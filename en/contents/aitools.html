prompt-expert

Speak your prompts, and drop in file paths with a single click

Windows 10 · 11Freev0.1.1Speech recognition runs on your PC
github.com/uengine-oss/prompt-expert

The two most tedious parts of handing work to an AI are typing long prompts and finding and pasting file locations. prompt-expert transcribes what you say while you hold the Alt key and types it into the input box, and copies a file path with a single right-click in File Explorer.

Demo (1 min 32 s) · writing a prompt by voice and inserting a data file path with Copy Path

Hold Alt to dictate

  • Hold Alt, speak, and release: the transcribed text is typed right where your cursor is.
  • Works in most input boxes, from Notepad to AI chat windows in your browser.
  • Korean and English are detected automatically, and a waveform animation appears on screen while recording.
  • Speech is processed on your PC by the OpenAI Whisper model and is never sent over the internet.

Copy Path in File Explorer

  • Right-click a file or folder → Show more options → Copy Path to copy the full path without quotes.
  • Recent Paths brings back the last 10 paths you copied.
  • Open Paths opens the files and folders of recent paths directly.
  • The path history stays on this PC only.

How to use it

  1. Install Run the installer. No administrator rights are needed. You can choose the recording animation, the Explorer menu and whether it starts automatically on the setup screen.
  2. Get ready On first launch it downloads the speech recognition model once. When the microphone icon on the taskbar turns blue, it's ready.
  3. Speak Place your cursor in the prompt box, hold Alt while you speak, then let go.
  4. Insert a path Right-click a file in File Explorer, choose Copy Path, and paste it into your prompt with Ctrl+V.

Good to know

  • On first launch it downloads a speech recognition model once. PCs without a graphics card (NVIDIA GPU) automatically use the fast small model (about 0.5 GB); PCs with a GPU use the more accurate large-v3-turbo (about 1.6 GB). While it downloads, the screen shows "Preparing model".
  • If you switch to another window while it is transcribing, the result is left on the clipboard instead of being pasted. Paste it wherever you want with Ctrl+V.
  • This version is not yet code-signed, so your browser may hold the download. Click Keep in the download list. If a Windows SmartScreen warning appears when you run it, click More info → Run anyway to install.
  • On Windows 11, the Copy Path menu appears under Show more options (or Shift+F10) after you right-click.

Gyeol Writer

An HWPX (Korean Hangul word-processor) document editor you write with AI

macOS · WindowsFree · open source (MIT)v0.3.1Uses your installed Claude Code · Codex
github.com/uengine-oss/gyeol-writer

Reports, plans and official letters in Korea still travel as Hangul documents. Gyeol Writer is a desktop word processor that opens and edits HWPX and HWP documents and saves them as HWPX, and in the AI Assistant pane on the right it calls the Claude Code or Codex installed on this computer to write body text, revise a selection, and edit or draw figures. There is nothing to sign up for and no API key to enter: it simply uses the agent account each person already has.

Demo (2 min 1 s) · write body text → revise a selection → edit a figure → draw a figure → ask. The results on screen are real Claude Code and Codex runs; waiting periods are sped up. · Watch on YouTube

AI Assistant

  • Write into the body: writes paragraphs, headings, lists and tables at the cursor, in keeping with the flow of the document.
  • Revise a selection: rewrites only the selected text, for example into official-document style, bullet style, corrected spelling or a translation.
  • Edit or draw figures: edits the selected figure, or draws a workflow or diagram and inserts it.
  • Ask: answers questions about the document without touching the body. Any result can be reverted with a single undo.

Hangul document editing

  • Open and save HWPX, open HWP 5.0 (saved as HWPX), template files (HWTX), save as PDF, print
  • Character and paragraph formatting, styles, page setup, page view, tables (merge cells, background color), insert and crop images
  • Find and replace, formatting marks, zoom in/out, drag and drop a document file to open it
  • Even the tables and figures the AI inserts are saved in HWPX, so the file opens as is in Hangul.

How to use it

  1. Install Download the installer for your operating system below and install it.
  2. Set up an agent Install Claude Code (npm i -g @anthropic-ai/claude-code) or Codex (npm i -g @openai/codex) and log in once.
  3. Open the AI Assistant Click AI Assistant (⌘J / Ctrl+J) at the right end of the toolbar, and it finds the installed agents automatically.
  4. Hand it the work Select text or a figure, or place the cursor, then type what you want done and send it.

Good to know

  • This version is not yet code-signed. On macOS, right-click the app the first time and choose Open; on Windows, click More info → Run anyway in the SmartScreen warning.
  • The AI Assistant runs the claude and codex commands on this computer. Document content is sent to each agent's service, so choose an agent that fits your company's security policy.
  • It was built from scratch on the public formats (HWPX/OWPML, HWP 5.0), without analyzing the code of Hancom Office Hangul. Where Korean fonts are not installed, some line breaks may differ.
  • Source code and all releases: github.com/uengine-oss/gyeol-writer

Copy Path for Mac

Put the paths of reference files into your prompt, fast

macOS 13 or laterApple SiliconFreev1.2

Right-click your reference material in Finder and the full path is copied instantly. Give an AI tool that can read local files the path together with your instructions, and pull frequently used material back from the recent list.

How to use it on a real Mac · about 1 min 15 s · Korean voice narration

Copy Path · Recent Paths

  • Copies the absolute path of a file or folder without quotes.
  • Shows the last 10 paths by file name and parent path, and copies them again.

Open Paths

  • Opens recent documents in their default app and folders in Finder.
  • The path history is stored on your Mac; no account or API key is needed.

Install and use

  1. Unzip the file and move Copy Path.app to your Applications folder.
  2. Launch the app and turn on Copy Path in Finder extension settings.
  3. Right-click a file in Finder → choose Copy Path, and paste it into your prompt with ⌘V.

Download Copy Path

macOS · Apple Silicon (M series) · v1.2

Download for Mac (.zip)
  • This build is distributed before Apple Developer ID signing and notarization, so macOS may block it from running. Check the source, then decide for yourself whether to allow it under Privacy & Security in System Settings.
  • This is not a package for Intel Macs. It was built for macOS 13, and real-world use was verified on macOS 26.
  • A regular web AI chat does not receive a file's contents from its path alone. You need file attachment or local file access.
  • Source code and releases · Windows users, please use prompt-expert above.
