Our Products

uEngine6-BPM

uEngine is a platform supporting SOA MM Level 7, covering everything from BPM-based architecture analysis to operations automation in one place

uEngine6 BPM is a Business Process Management System (BPMS) built on the latest cloud-native architecture, equipped with the ability to automate process definition, form generation, and application integration through Process GPT, uEngine's AI edition. This AI capability handles complex processes automatically, fully automating everything through the execution stage without direct user intervention.

Using an Event-Driven Architecture (EDA), it minimizes dependencies between services, synchronizes application progress, and manages everything without cascading failures. It also models automated retries, compensation, and timeouts for system integrations, reliably handling the transaction processing that is typically so complex in a microservices architecture.

Built on LLM AI technology, it performs process modeling, form generation, and more automatically through natural-language processing, effectively supporting a wide range of business requirements including system integration. uEngine6 BPM is the ideal solution for enterprises looking to move to cloud-native and microservices architectures.

Full Support of BPMN 2.0

uEngine6 fully supports the OMG BPMN 2.0 specification, providing process orchestration that efficiently mashes up microservices running on OCE and exposed as REST APIs. You can also create simple process-based REST microservices using nothing but pure BPMN.
“

Subprocesses

Multi-instance processing with subprocesses
- Multiple Instance (MI) is an advanced process execution feature in which the number of executions of a given section is determined at runtime. To specify MI, a SubProcess defines the scope of the MI execution section; when you set a process variable holding the triggering values (an array) in the SubProcess configuration, MI is generated dynamically, repeating in Parallel or Loop mode once for each value in that variable.
“

Conditional branching

Process branching with gateways
- Gateways let you model conditional branches and define rules, from simple process-variable comparisons to complex And / Or combinations.
“

Form mapping

Data transfer between activities using the Data Mapper
- A configuration tool for linking and transforming data across different schemas, enabling integration with other tools (i.e. Legacy Systems) during process execution

Our Values

Why did uEngine open-source its BPM product?

The uEngine BPM project offers as open source a BPMS product that was previously accessible only through expensive licensing fees, together with training and consulting services for adopting it. This enables thorough training and internalization through a consulting-centered budget structure, faithful customization centered on customer requirements thanks to the availability of source code, and multiple service channels. Among the considerations for BPM adoption, the technical ones come down to how easily the product can be customized and how easily it can be integrated into your organization's system environment without undue burden. To achieve this customizability and low-risk integration, the uEngine BPMS architecture applies IoC (Inversion of Control), the approach of an "object-oriented component framework," and the concept of "design reuse." It provides component interfaces such as separation of org-chart lookup logic, componentized activity types, and listeners for engine events, forming a refined boundary between BPM hot-spot services (fixed parts) and frequently customized BPM elements (variable parts). As services of the fixed parts, it provides foundational capabilities such as automatic generation of activity component UIs via reflection, instance data management, MQ handling, and OLAP analysis, so developers can customize easily without ever having to worry about the underlying BPM technology. This approach applies the same approach already used by Spring Framework and various other frameworks to the domain of BPM-based system development, providing a technical foundation that dramatically reduces the risk of BPM products that are typically offered only as packages allowing Server/Client integration, and maximizes availability.

Related products

Beyond uEngine6 BPM: the AI editions

uEngine6 BPM is the engine that defines and executes workflows for people and systems. Add Process GPT, where AI agents become the executors of work, and uEngine RPA, which takes over screen-level repetitive tasks, and design → execution → automation connect into one.

Process GPT — AI edition

Generate BPMN processes from a single line of natural language, and let AI agents perform tasks in place of people. It attaches MCP·A2A multi-agents to the workflows you have formalized with uEngine6 BPM to autonomously execute end-to-end work: the AI edition of uEngine6 BPM.

See Process GPT

uEngine RPA — execution automation

It handles the last-mile repetitive tasks of a process in place of human hands. Describe what you want automated in words, and the AI builds the automation script; from then on it runs repeatedly with no AI invocation cost. It is especially useful for connecting systems without APIs, such as legacy screens, to a process.

See uEngine RPA
