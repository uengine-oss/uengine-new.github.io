Cloud Native Architecture

CNA/MSA Consulting

전자정부 표준 프레임워크 기반, 마이크로서비스 아키텍처 전환을 위한 uEngine의 서비스는 두 축으로 구성됩니다 — 조직의 시스템을 함께 바꾸는 컨설팅, 그리고 조직의 사람을 키우는 교육.

전자정부 표준

표준 프레임워크 기반 실무 기준

MSA School을 운영하는 uEngine의 실전 컨설팅 & 교육

uEngine솔루션즈는 클라우드 네이티브 애플리케이션(CNA) 전문 배움터 MSA School을 직접 운영하며, 도메인 주도 설계(DDD)·이벤트스토밍부터 마이크로서비스 구현 패턴, 배포/운영까지 전 과정을 컨설팅과 교육으로 함께 제공합니다.

SAFe 공인 컨설턴트이자 디지털플랫폼정부 기술자문위원인 장진영 대표를 비롯한 실전 전문가진이 다분야 MSA 프로토타이핑 컨설팅 경험을 바탕으로, 이론에 그치지 않고 실제 조직의 아키텍처 전환을 함께 만들어갑니다.

① 컨설팅 서비스 — 시스템을 바꿉니다

레거시 진단 → 서비스 경계 설계 → 선도개발 구현 → 운영 안정화의 4단계로 진행되며, 각 단계에 Robo Analyzer(진단)와 Robo Architect(구현) 도구가 결합됩니다.

② 교육 서비스 — 사람을 키웁니다

성숙도 모형(CNMM)을 기준으로, 설계·구현·배포를 다루는 공개 세미나(Part 1~3)와 약 6개월의 정규 Professional 과정(Lv1~3·캡스톤)으로 팀 역량을 내재화합니다.

Consulting Service

컨설팅 프로세스

진단부터 운영 안정화까지, 사람(전문가)과 도구(Robo Analyzer·Robo Architect)가 함께 움직입니다

1. 진단

Robo Analyzer로 레거시를 자동 분석하고, 컨설턴트가 현황을 함께 인터뷰합니다.

2. 서비스 경계 설계

DDD·이벤트스토밍으로 코어/서포팅 도메인을 분류하고 바운디드 컨텍스트 경계를 함께 설계합니다.

3. 선도개발 구현

마이크로서비스 패턴을 적용한 선도개발을 수행하고, Robo Architect로 검증된 코드를 자동 구현합니다.

4. 운영 안정화

GitOps 기반 배포 자동화와 모니터링·장애 대응 체계를 구축하고 조직에 내재화합니다.

컨설팅 도구 ① 진단

Robo Analyzer — 진단부터 시작하는 컨설팅

컨설팅의 첫 단계는 언제나 ‘현황 진단’입니다. Robo Analyzer가 기존 레거시 시스템을 자동으로 분석해 강결합 지점, 서비스 분해 후보, 마이그레이션 우선순위를 도출하면, 이를 실제 시스템의 서비스 경계 설계에 그대로 적용합니다.

감(感)에 의존한 레거시 분석이 아니라, 도구가 산출한 정량적 근거 위에서 DDD 기반 서비스 경계를 함께 설계합니다.

레거시 코드 자동 분석 → 서비스 분해 후보 도출
진단 결과가 DDD·이벤트스토밍 설계의 실습 대상으로 연결
정량 근거 기반 마이그레이션 우선순위 수립
Robo Analyzer 살펴보기

컨설팅 도구 ② 구현

Robo Architect — 설계를 자동 구현으로

컨설팅에서 도출한 Aggregate·이벤트스토밍 모델과 마이크로서비스 구현 패턴은, Robo Architect의 Spec-Driven Development 엔진을 통해 실제 코드로 자동 구현됩니다. 교육으로 팀의 설계 역량을 내재화하고, 도구로 구현 속도를 확보하는 두 축이 함께 움직입니다.

컨설팅에서 도출한 도메인 모델과 서비스 경계는 Robo Architect의 프로포절로 그대로 이어져, 명세와 구현이 어긋나지 않습니다.

설계한 도메인 모델 → Robo Architect 프로포절로 이관
마이크로서비스 패턴의 코드·테스트 자동 생성
명세↔구현 일치로 컨설팅 결과의 현장 정착
Robo Architect 살펴보기

교육 ① 공개 세미나

설계·구현·배포 세미나 시리즈 (Part 1·2·3)

공공 서비스 민원처리 실습과 근로복지공단 ‘산재신청’ 사례를 관통 예제로 삼아, 이론에 그치지 않고 실제 요구사항에 패턴을 적용합니다. 전체 강의자료는 PDF로 바로 확인하실 수 있습니다.

Part 1. 설계

DDD와 이벤트스토밍

도메인 주도 설계의 전략(바운디드 컨텍스트, 코어·서포팅·제네릭 도메인 분류)과 전술(Aggregate·불변식) 패턴을 다룹니다. 5색 스티커 이벤트스토밍으로 도메인 이벤트·커맨드·액터·정책을 도출하고, 공공 민원처리 실습에서는 MSAez.io로 이벤트스토밍부터 전자정부 표준 프레임워크 기반 코드 생성까지 직접 체험합니다.

바운디드 컨텍스트 코어·서포팅·제네릭 도메인 Aggregate·불변식 이벤트스토밍(5색 스티커) Hexagonal·클린 아키텍처 전자정부 표준 프레임워크 MSAez.io 실습(민원처리 앱)
자료(PDF) 다운로드

Part 2. 구현

마이크로서비스 패턴

근로복지공단 ‘산재신청’ 사례를 관통 예제로, API Gateway·서킷 브레이커로 장애를 격리하고 SAGA(오케스트레이션·코레오그라피)로 분산 트랜잭션을 관리합니다. CQRS·이벤트소싱·EDA(Kafka)로 데이터 프로젝션을 구성하고, 컨트랙트 테스트·JWT/Keycloak 보안·컨테이너 패키징까지 구현 전 과정을 다룹니다.

API Gateway·서킷 브레이커 SAGA(오케스트레이션·코레오그라피) CQRS·이벤트소싱 EDA·Kafka GraphQL·BFF 컨트랙트 테스트(CDC) JWT·Keycloak 보안 컨테이너 패키징(Docker)
자료(PDF) 다운로드

Part 3. 배포/운영

마이크로서비스 배포/운영

서비스 도커라이징과 배포 모델 설계(고가용성·오토스케일·리질리언스)부터 GitOps(ArgoCD) 기반 배포 자동화, K8sGPT 등 AIOps 도구를 활용한 쿠버네티스 오케스트레이션까지 다룹니다. Istio 서비스 메시와 PLG·Zipkin 옵저버빌리티, SLI/SLO/Error Budget 기반 Cloud Native SRE로 운영 안정화를 완성합니다.

Docker 패키징 배포 모델 설계(HPA·리질리언스) GitOps·ArgoCD 쿠버네티스 오케스트레이션 AIOps(K8sGPT) 서비스 메시(Istio) 옵저버빌리티(PLG·Zipkin) Cloud Native SRE(SLI/SLO)

교육 ② 정규 과정

클라우드 네이티브 Professional 과정 (약 6개월)

성숙도 모형 Lv2→Lv4 도달을 목표로 하는 집중 양성 과정입니다. AI 기반 오리엔테이션부터 캡스톤 프로젝트까지, 매 단계 미니 프로젝트로 검증하며 진행합니다.

단계 기간 목표 주요 내용
오리엔테이션 1주 AI 기반 개발 프로세스 이해 Cursor IDE·GPT-Engineer 실습, Kubectl AI·K8sGPT 등 AIOps 도구 체험, 팀·미션 구성
Lv1 Fundamental 1개월 VM 기반 앱 개발 역량 (CNMM Lv2) 자바·객체지향·디자인 패턴·UML, 스프링 부트·JPA·REST, React.js·MUI 프론트엔드, 미니 프로젝트
Lv2 Intermediate 1.8개월 클라우드 네이티브 앱 구현 (CNMM Lv3) DDD·이벤트스토밍, 마이크로서비스 구현, Kafka·Saga(Axon), API 게이트웨이·인증인가, GraphQL·CQRS, 컨트랙트 테스트, 미니 프로젝트
Lv3 Advanced 1.3개월 경쟁력 있는 클라우드 앱 설계 (CNMM Lv4) 애자일 기획·분석(SAFe·BDD), 도커 패키징, AWS·Azure 쿠버네티스, 서비스 메시, GitOps·CI/CD, LLM 앱 개발
캡스톤 프로젝트 3주 실무 프로젝트 능력 완성 과제 플래닝(Biz) → 구현(Dev) → 운영(Ops) → 개선의 2차 이터레이션, 평가위원 발표 평가

MSA School 플랫폼에서 운영됩니다

정규 과정은 uEngine이 직접 운영하는 클라우드 네이티브 전문 배움터 MSA School(msaschool.io)에서 진행됩니다. 브라우저 기반 클라우드 IDE로 설치 없이 실습하고, 강사가 수강생 화면에 직접 들어와 페어 코딩으로 이끌어줍니다.

브라우저 기반 클라우드 IDE — 설치·환경설정 없는 실습
강사 실시간 화면 지원·AI 페어 프로그래밍
웨비나·세미나로 최신 MSA 트렌드 상시 공유
MSA School 바로가기 교육과정 제안서(PDF) 다운로드

교육 ③ 운영 체계

선발부터 사후처리까지

출석 확인에 그치지 않고, 선발·운영·프로젝트·평가의 전 과정을 체계적으로 관리합니다

1. 선발

Java·Spring·PaaS 사전 평가와 역량진단 설문으로 교육 목표에 맞는 교육생을 선발합니다.

2. 운영

HRD-Net 기반 출결 관리, 데일리 만족도 조사, 클라우드 IDE 실시간 화면 지원과 AI 기반 자체 문제해결 환경을 제공합니다.

3. 프로젝트

단계별 RFP 기반 미니 프로젝트와 최종 캡스톤 프로젝트, 종합 필기·실습 평가를 병행합니다.

4. 사후처리

개인·팀별 Radar Chart로 Skill Set을 분석해 보완 학습을 추천하고, 상위 10% 인력은 즉시 현장 프로젝트에 투입합니다.

왜 uEngine의 CNA/MSA Consulting인가

일반 교육기관의 이론 강의가 아니라, MSA School을 직접 운영하며 쌓아온 실전 컨설팅 경험과 자동화 도구가 결합된 프로그램입니다.

성숙도 모형 기반 체계

CNCF·SAFe를 통합한 자체 성숙도 모형(CNMM) 위에 커리큘럼·평가·수료 기준이 일관되게 설계되어, 교육이 일회성 행사가 아니라 조직의 역량 로드맵이 됩니다.

전자정부 표준 프레임워크

공공·민간 모두에 통용되는 전자정부 표준 프레임워크를 기준으로 설계·구현하여, 특정 벤더에 종속되지 않는 아키텍처를 제시합니다.

Robo Architect·Analyzer 연계

교육으로 쌓은 역량이 Robo Analyzer의 진단, Robo Architect의 자동 구현으로 이어져 현장에 실제로 정착됩니다.

그 결과, 교육으로 조직의 설계 역량을 남기고 도구로 구현 속도를 확보하는 — 지속 가능한 마이크로서비스 전환을 완성합니다.
