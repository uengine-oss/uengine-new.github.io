MSA School을 운영하는 uEngine의 실전 컨설팅 & 교육

uEngine솔루션즈는 클라우드 네이티브 애플리케이션(CNA) 전문 배움터 MSA School을 직접 운영하며, 도메인 주도 설계(DDD)·이벤트스토밍부터 마이크로서비스 구현 패턴, 배포/운영까지 전 과정을 컨설팅과 교육으로 함께 제공합니다.

SAFe 공인 컨설턴트이자 디지털플랫폼정부 기술자문위원인 장진영 대표를 비롯한 실전 전문가진이 다분야 MSA 프로토타이핑 컨설팅 경험을 바탕으로, 이론에 그치지 않고 실제 조직의 아키텍처 전환을 함께 만들어갑니다.

3단계 커리큘럼

전자정부 표준 프레임워크 기반의 클라우드 네이티브 애플리케이션 설계·구현·배포 자료를 PDF로 바로 확인하실 수 있습니다.

Part 1·2·3 상세 커리큘럼

공공 서비스 민원처리 실습과 근로복지공단 ‘산재신청’ 사례를 관통 예제로 삼아, 이론에 그치지 않고 실제 요구사항에 패턴을 적용해봅니다.

Part 1. 설계 — DDD와 이벤트스토밍

도메인 주도 설계의 전략(바운디드 컨텍스트, 코어·서포팅·제네릭 도메인 분류)과 전술(Aggregate·불변식) 패턴을 다룹니다. 5색 스티커 이벤트스토밍으로 도메인 이벤트·커맨드·액터·정책을 도출하고, 공공 민원처리 실습에서는 MSAez.io로 이벤트스토밍부터 전자정부 표준 프레임워크 기반 코드 생성까지 직접 체험합니다.
바운디드 컨텍스트 코어·서포팅·제네릭 도메인 Aggregate·불변식 이벤트스토밍(5색 스티커) Hexagonal·클린 아키텍처 전자정부 표준 프레임워크 MSAez.io 실습(민원처리 앱)

Part 2. 구현 — 마이크로서비스 패턴

근로복지공단 ‘산재신청’ 사례를 관통 예제로, API Gateway·서킷 브레이커로 장애를 격리하고 SAGA(오케스트레이션·코레오그라피)로 분산 트랜잭션을 관리합니다. CQRS·이벤트소싱·EDA(Kafka)로 데이터 프로젝션을 구성하고, 컨트랙트 테스트·JWT/Keycloak 보안·컨테이너 패키징까지 구현 전 과정을 다룹니다.
API Gateway·서킷 브레이커 SAGA(오케스트레이션·코레오그라피) CQRS·이벤트소싱 EDA·Kafka GraphQL·BFF 컨트랙트 테스트(CDC) JWT·Keycloak 보안 컨테이너 패키징(Docker)

Part 3. 배포/운영 — 마이크로서비스 배포·운영

서비스 도커라이징과 배포 모델 설계(고가용성·오토스케일·리질리언스)부터 GitOps(ArgoCD) 기반 배포 자동화, K8sGPT 등 AIOps 도구를 활용한 쿠버네티스 오케스트레이션까지 다룹니다. Istio 서비스 메시와 PLG·Zipkin 옵저버빌리티, SLI/SLO/Error Budget 기반 Cloud Native SRE로 운영 안정화를 완성합니다.
Docker 패키징 배포 모델 설계(HPA·리질리언스) GitOps·ArgoCD 쿠버네티스 오케스트레이션 AIOps(K8sGPT) 서비스 메시(Istio) 옵저버빌리티(PLG·Zipkin) Cloud Native SRE(SLI/SLO)

MSA School 연동

8,390명을 키운 MSA 전문 교육 플랫폼과 함께

이 컨설팅·교육과정은 uEngine이 직접 운영하는 클라우드 네이티브 전문 배움터 MSA School(msaschool.io)의 정규 커리큘럼과 그대로 이어집니다. Part 1·2·3 자료는 MSA School의 세미나·웨비나 콘텐츠에서 나온 실전 강의이며, 더 깊은 학습이 필요하면 MSA School의 상시 과정과 커뮤니티로 자연스럽게 확장됩니다.

컨설팅으로 조직에 맞는 실전 적용을 완료했다면, MSA School을 통해 사내 교육과정으로 넓혀 팀 전체의 역량으로 내재화할 수 있습니다.

8,390명 이상이 수료한 CNA 전문 과정
웨비나·세미나로 최신 MSA 트렌드 상시 공유
컨설팅 이후 사내 정규 교육과정으로 확장 가능

Robo Legacy Analyzer 연동

진단부터 시작하는 컨설팅

컨설팅의 첫 단계는 언제나 ‘현황 진단’입니다. Robo Legacy Analyzer가 기존 레거시 시스템을 자동으로 분석해 강결합 지점, 서비스 분해 후보, 마이그레이션 우선순위를 도출하면, Part 1(설계) 커리큘럼의 서비스 분해 요령을 실제 시스템에 그대로 적용합니다.

감(感)에 의존한 레거시 분석이 아니라, 도구가 산출한 정량적 근거 위에서 DDD 기반 서비스 경계를 함께 설계합니다.

레거시 코드 자동 분석 → 서비스 분해 후보 도출
Part 1(DDD·이벤트스토밍) 교육의 실습 대상으로 연결
정량 근거 기반 마이그레이션 우선순위 수립
Robo Legacy Analyzer 살펴보기

Robo Architect 연동

교육에서 배운 설계를 자동 구현으로

Part 1·2 커리큘럼에서 익힌 Aggregate·이벤트스토밍 모델링과 마이크로서비스 구현 패턴은, Robo Architect의 Spec-Driven Development 엔진을 통해 실제 코드로 자동 구현됩니다. 교육으로 팀의 설계 역량을 내재화하고, 도구로 구현 속도를 확보하는 두 축이 함께 움직입니다.

컨설팅에서 도출한 도메인 모델과 서비스 경계는 Robo Architect의 프로포절로 그대로 이어져, 명세와 구현이 어긋나지 않습니다.

교육 중 설계한 도메인 모델 → Robo Architect 프로포절로 이관
Part 2(마이크로서비스 패턴)의 코드 자동 생성
명세↔구현 일치로 교육 효과의 현장 정착

컨설팅 & 교육 프로세스

진단부터 운영 안정화까지, 사람(교육)과 도구(Robo Architect·Robo Legacy Analyzer)가 함께 움직입니다

1. 진단

Robo Legacy Analyzer로 레거시를 자동 분석하고, 컨설턴트가 현황을 함께 인터뷰합니다.

2. 설계 교육

Part 1(DDD·이벤트스토밍) 교육으로 팀 스스로 서비스 경계를 설계하는 역량을 내재화합니다.

3. 구현 컨설팅

Part 2(마이크로서비스 패턴)를 적용하고, Robo Architect로 검증된 코드를 자동 구현합니다.

4. 운영 안정화

Part 3(배포/운영) 교육과 함께 모니터링·장애 대응 체계를 구축하고 조직에 내재화합니다.

왜 uEngine의 CNA 컨설팅·교육인가

일반 교육기관의 이론 강의가 아니라, MSA School을 직접 운영하며 쌓아온 실전 컨설팅 경험과 자동화 도구가 결합된 프로그램입니다.

8,390명의 실전 경험

MSA School을 통해 8,390명 이상을 교육하고 다분야 MSA 프로토타이핑 컨설팅을 수행한 경험이 커리큘럼 곳곳에 녹아 있습니다.

전자정부 표준 프레임워크

공공·민간 모두에 통용되는 전자정부 표준 프레임워크를 기준으로 설계·구현하여, 특정 벤더에 종속되지 않는 아키텍처를 제시합니다.

Robo Architect·Analyzer 연계

교육으로 쌓은 역량이 Robo Legacy Analyzer의 진단, Robo Architect의 자동 구현으로 이어져 현장에 실제로 정착됩니다.

그 결과, 교육으로 조직의 설계 역량을 남기고 도구로 구현 속도를 확보하는 — 지속 가능한 마이크로서비스 전환을 완성합니다.
