Open Source PaaS · Kubernetes

uEngine Cloud

개발부터 배포·운영까지 연결하는 오픈소스 PaaS

GitHub 데모 영상 보기

2018년 공개 데모 · 현재 제품은 Kubernetes를 지원합니다.

마이크로서비스의 개발과 운영을
하나의 포털에서

uEngine Cloud는 Open Cloud Engine(OCE)의 오픈소스 PaaS 플랫폼입니다. Kubernetes를 지원하며, 셀프서비스 포털과 DevOps, 클라우드 오케스트레이션을 연결하여 서비스 생성부터 배포·운영까지의 작업 흐름을 제공합니다.

개발자는 템플릿과 Git 저장소로 작업을 시작하고, 운영자는 같은 앱 단위로 자원·배포 이력·로그를 확인합니다. 공개된 소스와 구성을 바탕으로 조직의 개발 환경에 맞게 확장할 수 있습니다.

주요 기능

셀프서비스 앱·인스턴스 관리

앱 목록에서 서비스 상태를 확인하고 인스턴스 수와 CPU·메모리를 조정합니다. 운영에 필요한 설정을 웹 포털에서 다룹니다.

앱별 실행 상태 확인
인스턴스 수 증감
CPU·메모리 자원 설정

환경 설정과 런타임 제어

환경변수와 SSH 접근, 고급 설정을 한 흐름에서 관리합니다. 세부 배포 설정이 필요한 경우 JSON 편집 화면을 활용합니다.

환경변수 분리 관리
인스턴스 SSH 접근
배포 설정 직접 편집

단계적 배포와 롤백

새 버전을 단계적으로 배포하고 진행 상태를 확인합니다. 블루그린·카나리 배포와 이전 버전으로의 롤백을 지원합니다.

버전별 배포 상태 확인
트래픽을 나누는 단계적 전환
롤백·스냅샷 관리

여러 인스턴스의 로그 통합

분산된 앱 로그를 모아 보고 검색합니다. Kibana와 연결된 화면에서 필터를 적용해 문제 원인을 좁혀 갑니다.

애플리케이션 로그 통합
키워드·필터 검색
Kibana 탐색 화면 연계

서비스 자원 모니터링

컨테이너 수와 CPU·메모리 등 운영 지표를 대시보드에서 살펴봅니다. 서비스 상태와 자원 사용량을 함께 확인할 수 있습니다.

컨테이너 현황 조회
CPU·메모리 지표 확인
대시보드 기반 상태 파악

GitLab 기반 CI/CD

소스 변경을 커밋하면 파이프라인이 빌드·이미지 생성·테스트·배포를 이어갑니다. 소스 저장소와 실행 환경을 연결해 반복 작업을 줄입니다.

Git 저장소·소스 이력 연계
빌드·컨테이너 이미지 생성
테스트·배포 단계 자동화

템플릿으로 시작하는 서비스

Spring Boot, Vue.js, Tomcat, Node.js 등 서비스 템플릿으로 앱을 생성합니다. 사내에서 사용하는 프로젝트 구성을 재사용할 수 있습니다.

서비스 유형별 시작 템플릿
GitHub·GitLab 저장소 연결
조직 공통 구성 재사용

IAM과 API 게이트웨이 구성

인증 서버와 라우터도 서비스 템플릿으로 생성합니다. 공개 저장소에는 OAuth2·JWT 기반 IAM과 Zuul·Eureka 연계 구성이 포함되어 있습니다.

IAM 서비스 템플릿
OAuth2·JWT 기반 인증 구성
Zuul 라우팅·서비스 레지스트리 연계

동작 방식

01

템플릿 선택

앱 유형을 선택하고 저장소·도메인·자원을 설정합니다.
02

코드 변경·빌드

Git 커밋에서 파이프라인을 시작하고 실행 이미지를 만듭니다.
03

테스트·배포

테스트 결과를 확인한 뒤 대상 환경으로 새 버전을 배포합니다.
04

관찰·개선

로그와 지표로 상태를 확인하고 확장·롤백·다음 변경을 결정합니다.

비교표 요약

개별 도구 구성과 uEngine Cloud의 작업 방식 비교
작업개별 도구를 직접 구성할 때uEngine Cloud
앱 생성프로젝트와 실행 환경을 개별 구성템플릿과 자원 설정으로 앱 생성
코드에서 배포까지저장소·빌드·배포 도구를 각각 연결GitLab과 포털에서 CI/CD 흐름 연결
버전 전환배포 상태와 복구 절차를 직접 관리배포 현황·롤백·스냅샷을 화면에서 관리
문제 탐색인스턴스별 로그와 자원 상태 확인통합 로그·서비스 대시보드 활용
기반 서비스인증·라우팅 구성부터 직접 시작IAM·라우터 템플릿 및 공개 코드 활용

제품 배경과 주요 사례

2003년 공개한 uEngine BPM에서 출발해, 2013년 OCE(Open Cloud Engine) 연합의 오픈소스 PaaS, 2018년 MSA 기반 DevOps로 발전해 왔습니다. 현재는 Kubernetes를 지원하며 설계·구현 도구인 Robo Architect와 배포·운영을 연결합니다. 이 과정에서 쌓은 경험을 기업 컨설팅과 MSA School 교육으로 나누고 있습니다.

Robo Architect 연동

설계한 서비스를 배포로 연결합니다

Robo Architect가 요구사항을 분석해 마이크로서비스를 설계·구현하고 검증합니다. 생성한 산출물은 uEngine Cloud에 배포되어 Kubernetes 환경에서 실행됩니다.

명세와 코드의 변경은 Robo Architect에서 관리하고, 빌드·배포와 실행 상태는 uEngine Cloud에서 관리합니다. 설계부터 운영까지 하나의 개발 흐름으로 연결합니다.

명세 기반 마이크로서비스 설계·구현

개인정보 수집 및 이용

유엔진솔루션즈(이하 "회사")가 문의하신 내용에 대한 답변을 제공하기 위해 개인정보를 수집·이용하고자 하는 경우에는 ｢개인정보 보호법｣등 관계 법령에 따라 본인의 동의가 필요합니다.
회사 제품 구매 및 컨설팅 문의 응답, 회사가 제공하는 서비스 이용과정을 위한 최소한의 개인정보를 수집하고 이용합니다.
수집된 정보는 발송 외 다른 목적으로 이용되지 않으며, 서비스가 종료될 경우 즉시 파기됩니다.

유엔진솔루션즈는 2003년 이래 업무 프로세스 관리 (Business Process Management), AI, MSA, 기업용 SNS, PaaS 를 포함한 클라우드 플랫폼, 도메인 기반 개발 방법을 지향하는 개발 프레임워크 등을 개발하고 오픈소스 프로젝트로 제공하는 기술 집약적 기업입니다.
