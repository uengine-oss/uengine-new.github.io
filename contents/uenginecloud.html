Open Source PaaS · Kubernetes

uEngine Cloud

Kubernetes 기반 개발자 셀프서비스 PaaS 포털

GitHub 데모 영상 보기 제품 소개서(PDF)

2026년 제품 데모 · 앱 생성부터 무중단 전환·노드 이동까지 약 6분

개발자는 코드에 집중하고,
배포와 운영은 포털에서

uEngine Cloud는 Kubernetes 위에서 동작하는 개발자 셀프서비스 PaaS 포털입니다. 카탈로그에서 서비스를 만들면 Git 저장소 생성, 이미지 빌드, 개발·스테이징·운영 배포까지 하나의 흐름으로 이어집니다.

개발자는 소스코드를 올리고, 운영자는 같은 앱 화면에서 자원·로그·지표와 배포 상태를 확인합니다. 검증한 이미지를 다시 빌드하지 않고 운영까지 올리며, 트래픽 전환과 이전 버전 복귀도 포털에서 처리합니다.

주요 기능

서비스 생성부터 운영까지, 실제 Kubernetes 클러스터에서 동작하는 제품 화면입니다.
화면을 누르면 크게 볼 수 있습니다. 표시된 앱과 수치는 데모 환경 기준입니다.

템플릿으로 시작하는 서비스

카탈로그에서 템플릿을 고르고 이름과 자원을 정하면 Git 저장소와 첫 배포 파이프라인이 준비됩니다. 조직의 표준 프로젝트를 재사용합니다.

Node.js · Spring Boot 3 · Vue 3 템플릿
Git 저장소 자동 생성과 소스 탐색
개발·스테이징·운영 접속 주소 안내

코드 반영부터 빌드·배포까지

소스코드를 올리면 클러스터 안에서 이미지 빌드 작업이 실행됩니다. 결과 이미지를 레지스트리에 등록하고 지정한 단계에 배포합니다.

자동 실행 여부·대상 브랜치 설정
단계별 진행 상태와 빌드 로그
자동 배포 단계·빌드 제한 시간 설정

개발에서 운영까지 같은 이미지로

개발 단계에서 검증한 이미지를 스테이징과 운영으로 올립니다. 단계마다 다시 빌드하지 않아 배포할 버전을 일관되게 관리할 수 있습니다.

개발·스테이징·운영 3단계 분리
동일 이미지의 단계별 승격
단계별 슬롯·커밋·접속 주소 확인

5종 배포 전략과 트래픽 전환

새 버전을 별도 슬롯에 배포하고 트래픽을 조정합니다. 전환을 확정하기 전에는 이전 슬롯을 유지하여 문제가 생기면 되돌릴 수 있습니다.

블루그린·카나리·A/B 테스트
세션 고정·롤링 속도 조절
신규 버전 비율 조정과 전환 확정

자원과 환경설정을 앱 단위로

인스턴스 수와 CPU·메모리를 화면에서 조정합니다. 단계별 환경설정을 편집하고 변경 내용을 확인한 뒤 재배포에 반영합니다.

인스턴스·CPU·메모리 조정
환경변수·설정 파일 관리
브라우저에서 컨테이너 셸 접속

실시간 로그 검색과 저장

실행 중인 인스턴스의 로그를 포털에서 이어 받습니다. 키워드와 심각도 필터로 문제를 좁히고 확인한 내용을 파일로 저장합니다.

인스턴스 선택과 실시간 수신
검색어 강조·오류·경고 필터
자동 스크롤·줄바꿈·파일 다운로드

앱의 상태와 운영 지표 확인

CPU·메모리 사용량과 정상 인스턴스 상태를 앱 단위로 살펴봅니다. 클러스터 이벤트를 함께 확인해 배포 이후의 변화를 추적합니다.

CPU·메모리 사용 추이
인스턴스 상태 확인
Kubernetes 이벤트 조회

이전 상태로 되돌리는 운영

슬롯 복귀, 과거 이미지 재배포, 스냅샷 복원을 제공합니다. 배포 버전뿐 아니라 환경설정과 자원 구성도 함께 보관합니다.

이미지·커밋·자원·배포 전략 저장
단계별 스냅샷 복원과 재배포
배포·승격·복원 조작 이력 추적

클러스터 맵과 노드 배치

개발·스테이징·운영의 전체 배포 현황과 노드별 자원 배치를 시각적으로 확인합니다. 워크로드를 선택해 다른 노드로 옮길 수 있습니다.

클러스터 맵에서 배포·전환 상태 확인
노드별 앱 메모리 사용량 비교
워크로드 이동·노드의 신규 배치 차단

여러 서비스를 묶어서 관리

함께 운영하는 서비스를 앱 그룹으로 묶어 승격하고 스냅샷을 남깁니다. 서비스별 처리 결과와 단계별 배포 현황을 확인합니다.

그룹 단위 스테이징·운영 승격
그룹 전체 스냅샷 생성
서비스별 성공·실패 결과 확인

동작 방식

01

템플릿 선택

카탈로그에서 앱 유형을 고르고 이름·자원을 정합니다. 저장소와 첫 빌드가 준비됩니다.
02

코드 변경·빌드

코드를 올리면 클러스터 내부에서 이미지를 빌드하고 개발 단계에 배포합니다.
03

검증·운영 승격

개발에서 확인한 이미지를 스테이징·운영으로 올리고 트래픽을 전환합니다.
04

관찰·개선

로그와 지표를 확인하고 전환을 확정합니다. 필요하면 이전 슬롯이나 스냅샷으로 복귀합니다.

서비스에 맞는 배포 전략

포털에서 선택하고 조정하는 5종 배포 전략
전략운영 방식
블루그린새 버전을 반대 슬롯에 배포하고 트래픽을 전환합니다. 확정 전까지 이전 슬롯을 유지합니다.
카나리신규 버전으로 보낼 트래픽 비율을 지정하고 점진적으로 조정합니다.
A/B 테스트지정한 요청 헤더를 가진 요청을 신규 버전으로 전달합니다.
세션 고정같은 사용자의 요청이 같은 인스턴스로 전달되도록 설정합니다.
롤링 속도교체 중 동시에 추가하거나 줄일 인스턴스의 비율을 조정합니다.

온프레미스 · 오픈소스

사내 환경에 맞게 설치하고 확장합니다

포털·저장소·레지스트리·인증 서버를 사내 Kubernetes 환경에 구성합니다. 필요한 이미지를 사전에 반입하면 폐쇄망에도 설치할 수 있습니다.

OAuth 2.0·OIDC 기반 인증과 관리자·일반 사용자 역할, 그룹 관리를 제공합니다. 기존 저장소·레지스트리·인증 체계의 연동 방식은 도입 환경에 맞춰 구성합니다.

MIT 라이선스로 소스가 공개되어 있어 템플릿과 화면을 조직 표준에 맞게 확장할 수 있습니다. 설치 구성·운영 문서·교육과 시범 서비스 적용을 함께 검토합니다.

제품 배경과 주요 사례

2003년 공개한 uEngine BPM에서 출발해, 2013년 OCE(Open Cloud Engine) 연합의 오픈소스 PaaS, 2018년 MSA 기반 DevOps로 발전해 왔습니다. 현재는 Kubernetes를 지원하며 설계·구현 도구인 Robo Architect와 배포·운영을 연결합니다. 이 과정에서 쌓은 경험을 기업 컨설팅과 MSA School 교육으로 나누고 있습니다.

Robo Architect 연동

설계한 서비스를 배포로 연결합니다

Robo Architect가 요구사항을 분석해 마이크로서비스를 설계·구현하고 검증합니다. 생성한 산출물은 uEngine Cloud에 배포되어 Kubernetes 환경에서 실행됩니다.

명세와 코드의 변경은 Robo Architect에서 관리하고, 빌드·배포와 실행 상태는 uEngine Cloud에서 관리합니다. 설계부터 운영까지 하나의 개발 흐름으로 연결합니다.

개인정보 수집 및 이용

유엔진솔루션즈(이하 "회사")가 문의하신 내용에 대한 답변을 제공하기 위해 개인정보를 수집·이용하고자 하는 경우에는 ｢개인정보 보호법｣등 관계 법령에 따라 본인의 동의가 필요합니다.
회사 제품 구매 및 컨설팅 문의 응답, 회사가 제공하는 서비스 이용과정을 위한 최소한의 개인정보를 수집하고 이용합니다.
수집된 정보는 발송 외 다른 목적으로 이용되지 않으며, 서비스가 종료될 경우 즉시 파기됩니다.

유엔진솔루션즈는 2003년 이래 업무 프로세스 관리 (Business Process Management), AI, MSA, 기업용 SNS, PaaS 를 포함한 클라우드 플랫폼, 도메인 기반 개발 방법을 지향하는 개발 프레임워크 등을 개발하고 오픈소스 프로젝트로 제공하는 기술 집약적 기업입니다.
