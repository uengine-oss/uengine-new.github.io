AI 도구 모음

업무에서 바로 쓰는 작은 AI 도구들입니다. 설치 한 번으로 오늘부터 일하는 방식을 바꿔 보세요.

prompt-expert 결 워드 (Gyeol Writer)

prompt-expert

말로 쓰는 프롬프트, 클릭 한 번으로 넣는 파일 경로

Windows 10 · 11무료v0.1.1음성 인식은 PC 안에서 처리
github.com/uengine-oss/prompt-expert

AI에게 일을 시킬 때 가장 번거로운 두 가지는 긴 프롬프트를 타이핑하는 일과 파일 위치를 찾아 붙여 넣는 일입니다. prompt-expert는 Alt 키를 누른 채 말하면 받아써서 입력창에 넣어 주고, 탐색기 우클릭 한 번으로 파일 경로를 복사하게 해 줍니다.

데모 (1분 32초) · 음성으로 프롬프트를 쓰고 Copy Path로 데이터 파일 경로를 넣는 과정

Alt 길게 눌러 받아쓰기

  • Alt를 누른 채 말하고 떼면, 받아쓴 글자가 지금 커서가 있는 곳에 바로 입력됩니다.
  • 메모장, 브라우저의 AI 채팅창 등 대부분의 입력창에서 동작합니다.
  • 한국어·영어를 자동으로 구분하고, 녹음 중에는 화면에 파형 애니메이션이 표시됩니다.
  • 음성은 OpenAI Whisper 모델로 PC 안에서 처리되며, 인터넷으로 전송되지 않습니다.

탐색기 Copy Path

  • 파일·폴더를 우클릭 → 더 많은 옵션 표시 → Copy Path로 전체 경로를 따옴표 없이 복사합니다.
  • Recent Paths로 최근 복사한 경로 10개를 다시 꺼내 쓸 수 있습니다.
  • Open Paths로 최근 경로의 파일·폴더를 바로 엽니다.
  • 경로 기록은 이 PC에만 남습니다.

사용 방법

  1. 설치 설치 파일을 실행합니다. 관리자 권한은 필요 없습니다. 녹음 애니메이션, 탐색기 메뉴, 자동 실행 여부를 설치 화면에서 고를 수 있습니다.
  2. 준비 처음 실행하면 음성 인식 모델을 한 번 내려받습니다. 작업 표시줄의 마이크 아이콘이 파란색이 되면 준비가 끝난 것입니다.
  3. 말하기 프롬프트 입력창에 커서를 두고, Alt를 누른 채 말한 뒤 손을 뗍니다.
  4. 경로 넣기 탐색기에서 파일을 우클릭해 Copy Path를 누르고, 프롬프트에 Ctrl+V로 붙여 넣습니다.

prompt-expert 다운로드

Windows 10 · 11 (64비트) · 설치 파일 66MB · 2026년 10월

설치 파일 받기 (.exe)

알아 두실 점

  • 첫 실행 때 음성 인식 모델을 한 번 내려받습니다. 그래픽카드(NVIDIA GPU)가 없는 PC는 빠른 small 모델(약 0.5GB)을, GPU가 있으면 더 정확한 large-v3-turbo(약 1.6GB)를 자동으로 씁니다. 받는 동안에는 화면에 "모델 준비 중"이 표시됩니다.
  • 받아쓰는 사이 다른 창으로 옮겨 가면 결과를 붙여 넣지 않고 클립보드에 남겨 둡니다. 원하는 곳에서 Ctrl+V로 붙여 넣으세요.
  • 코드 서명 전 버전이라 브라우저가 다운로드를 보류할 수 있습니다. 다운로드 목록에서 유지를 누르세요. 실행할 때 Windows SmartScreen 경고가 뜨면 추가 정보 → 실행을 누르면 설치됩니다.
  • Copy Path 메뉴는 Windows 11에서 우클릭 후 더 많은 옵션 표시(또는 Shift+F10) 안에 나타납니다.
  • 소스 코드와 모든 버전: github.com/uengine-oss/prompt-expert
  • 설치 파일 SHA-256: 53a98b083c615ce8e246fe576e485287e4158bbd5625c5de31183169eebf165b

결 워드 Gyeol Writer

AI와 함께 쓰는 한글(HWPX) 문서 편집기

macOS · Windows무료 · 오픈소스(MIT)v0.3.1설치된 Claude Code · Codex 사용
github.com/uengine-oss/gyeol-writer

보고서·계획서·공문은 여전히 한글 문서로 오갑니다. 결 워드는 HWPX·HWP 문서를 열고 편집해 HWPX로 저장하는 데스크톱 워드프로세서이고, 오른쪽 AI 도우미 창에서 이 컴퓨터에 설치된 Claude Code나 Codex를 불러 본문을 쓰고, 선택한 부분을 고치고, 그림을 고치거나 그려 넣습니다. 따로 가입하거나 API 키를 넣을 필요 없이 각자 쓰는 에이전트 계정을 그대로 씁니다.

데모 (2분 1초) · 본문 쓰기 → 선택 부분 고치기 → 그림 고치기 → 그림 그리기 → 묻기. 화면의 결과는 실제 Claude Code·Codex 실행 결과이며 기다리는 구간은 빨리 감았습니다. · YouTube에서 보기

AI 도우미

  • 본문에 쓰기: 커서 자리에 문단·제목·목록·표를 문서 흐름에 맞게 써 넣습니다.
  • 선택 부분 고치기: 선택한 글자만 공문서 문체·개조식·맞춤법·번역 등으로 바꿔 넣습니다.
  • 그림 고치기 · 그리기: 선택한 그림을 고치거나, 업무 흐름도·도식을 그려 넣습니다.
  • 묻기: 본문은 그대로 두고 문서에 대해 답합니다. 결과는 되돌리기 한 번으로 되돌립니다.

한글 문서 편집

  • HWPX 열기·저장, HWP 5.0 열기(HWPX로 저장), 서식 파일(HWTX), PDF 저장, 인쇄
  • 글자·문단 모양, 스타일, 편집 용지, 쪽 단위 화면, 표(셀 합치기·배경색), 그림 넣기·자르기
  • 찾기·바꾸기, 조판 부호, 확대/축소, 문서 파일 끌어 놓아 열기
  • AI가 넣은 표와 그림까지 HWPX로 저장되어 한글에서 그대로 열립니다.

사용 방법

  1. 설치 아래에서 운영체제에 맞는 설치 파일을 받아 설치합니다.
  2. 에이전트 준비 Claude Code(npm i -g @anthropic-ai/claude-code) 또는 Codex(npm i -g @openai/codex)를 설치하고 한 번 로그인합니다.
  3. AI 도우미 열기 도구 상자 오른쪽 끝 AI 도우미(⌘J / Ctrl+J)를 누르면 설치된 에이전트를 자동으로 찾습니다.
  4. 맡기기 글자나 그림을 선택하거나 커서를 두고, 하고 싶은 일을 적어 보냅니다.

결 워드 다운로드

v0.3.1 · macOS(Apple Silicon·Intel) DMG 약 110MB · Windows 10·11(64비트) 약 90MB · 2026년 10월

macOS (Apple Silicon) macOS (Intel) Windows (.exe)

알아 두실 점

  • 코드 서명 전 버전입니다. macOS는 처음 한 번 앱을 우클릭 → 열기, Windows는 SmartScreen 경고에서 추가 정보 → 실행을 누르세요.
  • AI 도우미는 이 컴퓨터의 claude·codex 명령을 실행합니다. 문서 내용은 각 에이전트 서비스로 전달되므로, 회사 보안 정책에 맞는 에이전트를 고르세요.
  • 한컴오피스 한글의 코드를 분석하지 않고, 공개 형식(HWPX/OWPML, HWP 5.0)을 바탕으로 새로 구현했습니다. 한글 글꼴이 없는 환경에서는 줄바꿈이 일부 다를 수 있습니다.
  • 소스 코드와 모든 버전: github.com/uengine-oss/gyeol-writer
