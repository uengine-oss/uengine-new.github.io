AI-Driven Development

Robo Analyzer

코드와 데이터의 연결을, 읽을 수 있는 그래프로.
레거시 소스 코드와 데이터베이스 스키마를 함께 분석해 함수 호출과 테이블 읽기·쓰기 관계를 하나의 그래프로 보여줍니다. 어느 지점에서든 실제 코드 원문까지 내려갈 수 있습니다.

전체 데모 영상 보기 주요 기능 보기

약 4분 47초 · 내레이션은 합성 음성(OpenAI TTS)입니다. 소리를 켜고 보시면 각 화면의 설명을 함께 들으실 수 있습니다.

코드만 읽어서는 알 수 없는 것들

오래된 시스템은 코드만 읽어서는 실제 호출 흐름을 알기 어렵습니다. 테이블이 어디에서 읽히고 쓰이는지 문서와 코드가 서로 어긋납니다.

Robo Analyzer는 현재 시스템을 코드와 데이터 근거로 이해하는 단계에 집중합니다. 분석 이후의 명세·설계·구현 자동화는 별도 제품이 담당합니다.

레거시에는 늘 같은 질문이 남습니다

이 함수를 고치면
어디까지 영향이 갑니까?

이 테이블은 지금
누가 읽고 누가 씁니까?

문서와 코드가 다르면
무엇을 믿어야 합니까?

답을 아는 사람은 대개 회사에 없거나, 있어도 확신하지 못합니다.

Robo Analyzer의 핵심 차별점

LLM 없이 계산되는 구조

구조·관계·군집·위험도는 LLM 없이 계산합니다. AI는 의미를 붙일 때만 씁니다.

깨진 코드도 분석

실패한 부분만 복구를 시도하고, 안 되면 남기고 진행합니다. 원본은 수정하지 않습니다.

진행이 실시간으로

파싱과 분석 양쪽에서 단계·콘솔·노드 수가 완료 전부터 계속 갱신됩니다.

업무 언어로 검색

"재고를 예약했다가 부족하면 취소하는 부분" — 문장 그대로 관련 코드를 찾습니다.

원문으로 증명

모든 결과가 실제 파일과 줄 번호로 이어집니다. 근거 없는 그림이 아닙니다.

운영 DB는 읽기 전용

조회만 허용하고 쓰기를 차단하며, 접속 비밀번호는 어디에도 저장하지 않습니다.

코드를 열어보는 것만으로는 알 수 없습니다

질문 지금까지 Robo Analyzer
호출 영향 범위이름을 추측해 반복 검색호출과 읽기·쓰기를 하나의 그래프로
데이터 출처SQL과 코드를 따로 조사테이블에서 함수와 코드 줄로 바로 이동
업무 경계담당자 기억과 오래된 문서에 의존모듈과 업무 단위를 분석 결과로 비교
진행 상태끝날 때까지 결과를 모름단계·콘솔·그래프 수를 실시간 확인
재확인확인할 때마다 처음부터 다시한 번 분석하고 계속 탐색

구조만 보여주고 끝나지 않습니다

컴파일도 안 되는 코드를 받아본 적 있습니까

레거시 소스에는 문법이 깨진 파일이 섞여 있는 것이 정상입니다. 정상 파일은 그대로 처리하고, 실패한 부분만 문법 규칙 기반으로 복구를 시도합니다. 그래도 안 되면 그 부분만 남기고 다음 파일로 넘어갑니다.

기본 설정에서 원본 소스 파일은 수정하지 않습니다.

업무 규칙과 위험 지점까지

코드 안에 흩어져 있는 판단 조건을 규칙으로 뽑아냅니다. 예를 들어 “잔액이 0보다 크면 출금 허용” 같은 규칙입니다. 규칙과 사례, 확인이 필요한 질문으로 정리되고 관련 테이블과 연결됩니다.

함수마다 불려지는 횟수, 부르는 횟수, 코드 길이, 순환 참조 여부, 테이블 결합도를 계산해 낮음·보통·높음 등급을 매깁니다.

파일 공유는 코드 파서와 분석 엔진 사이에만 존재합니다.

자주 묻는 질문

어떤 소스 언어를 분석할 수 있나요?

Java, C, Python, Oracle PL/SQL, PostgreSQL을 파일 내용에서 자동 감지합니다. 사용자가 타깃 언어를 직접 지정할 필요가 없습니다.

운영 DB 연결 없이 시작할 수 있나요?

가능합니다. 소스 코드와 DDL만으로 분석을 시작할 수 있습니다. 운영 DB를 함께 등록하면 코드에서 발견한 테이블 접근을 실제 스키마와 대조할 수 있습니다.

운영 DB에 붙여도 안전한가요?

조회 구문만 허용하고 쓰기·변경·삭제는 차단합니다. 가져오는 행 수에 서버가 상한을 씌우며, 접속 비밀번호는 저장소·응답·로그 어디에도 남지 않습니다.

문법이 깨진 파일이 있으면 어떻게 되나요?

실패한 부분만 복구를 시도하고, 안 되면 그 부분만 남기고 다음 파일로 넘어갑니다. 분석 전체가 멈추지 않으며 원본 소스 파일은 수정하지 않습니다.

분석 결과를 AI가 지어낸 건 아닌가요?

구조와 관계, 군집, 위험도는 LLM을 쓰지 않고 계산합니다. AI는 함수 요약이나 규칙 문장화처럼 의미를 붙일 때만 사용합니다.

우리 시스템으로 확인해 보세요

보유하신 소스 코드와 데이터베이스로 Robo Analyzer가 무엇을 찾아내는지 함께 확인합니다.
데모 상담을 요청하시면 담당자가 연락드립니다.
