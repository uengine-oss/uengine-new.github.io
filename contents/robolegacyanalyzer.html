AI Reverse Engineering

Robo Legacy Analyzer

지저분한 레거시 코드를 그래프로 시각화하고, 자연어로 검색해 호출 사슬까지 추적하는 AI 리버스 엔지니어링 도구

데모 영상 Part 1 — 분석 데모 영상 Part 2 — 전환

코드를 읽지 않고도 레거시를 이해하는 그래프

Robo Legacy Analyzer는 Robo Architect의 Legacy 탭입니다. 순환 참조와 거대 함수가 뒤섞인 12,000줄 이상의 쇼핑몰 레거시 코드를 테이블 DDL과 함께 통째로 업로드하면, DDL 파싱 → AST 로딩 → 코드베이스 스캔 → 호출·읽기/쓰기 관계 추론 → 협업 클러스터 탐지로 이어지는 파이프라인이 코드를 하나의 그래프로 재구성합니다.

실제 변수명 대신 읽기 좋은 논리명으로, 긴 코드 대신 정리된 업무 규칙으로 훑어볼 수 있고, 자연어 문장 하나로 원하는 로직과 그 호출 사슬 전체를 바로 찾아낼 수 있습니다.

주요 기능

DB 스키마 그대로 연결

PostgreSQL·MySQL·MariaDB 등 운영 중인 데이터베이스에 직접 연결해 스키마를 가져옵니다. 호스트·계정·데이터베이스명을 입력하고 연결 테스트로 바로 확인합니다.

PostgreSQL 등 주요 RDB 지원
연결 테스트로 즉시 검증
등록 후 메타데이터 자동 추출

소스코드 + DDL 통째로 업로드

순환 참조와 거대 함수가 뒤섞인 12,000줄 이상의 레거시 코드를 테이블 DDL과 함께 업로드합니다. 어떤 파일이 분석 대상인지 확인한 뒤 시작합니다.

소스 파일 + DDL 동시 업로드
FK 관계 자동 추론 옵션
분석 대상 파일 목록 확인

DDL→AST→관계 추론 자동 파이프라인

DDL 파싱, 코드 AST 로딩, 코드베이스 프레임워크 스캔, 호출·테이블 읽기/쓰기 관계 연결, 분석 컨텍스트 그룹핑까지 콘솔 로그로 진행 상황을 보여주며 자동으로 처리합니다.

DDL 파싱 & AST 로딩
프레임워크 자동 감지
함수 단위 분석 진행 로그

노드 클릭 한 번으로 업무 규칙까지

테이블·컬럼·함수 노드를 클릭하면 원문 코드는 물론 코드 속에 숨어 있던 업무 규칙을 정리된 문장으로 보여줍니다. 호출·피호출 관계도 함께 확인됩니다.

노드별 업무 규칙 자동 요약
원문 코드 즉시 조회
호출·피호출 관계 연결 표시

자주 협력하는 함수는 자동으로 군집화

호출 관계를 분석해 자주 함께 일하는 함수들을 클러스터로 묶고 어울리는 이름까지 붙여줍니다. 쇼핑몰·외부 호출·테이블이 서로 어떻게 주고받는지 모듈 간 상호작용으로 한눈에 파악합니다.

협력 클러스터 자동 탐지 & 명명
모듈 간 상호작용 뷰
역할(Service/Repository 등) 레이블

위험 신호는 색으로 먼저 보인다

읽기는 파랑, 쓰기는 빨강으로 관계를 색칠해 어떤 함수가 쓰기에 편중돼 있는지 즉시 드러냅니다. 순환 참조 같은 위험 요소는 빨간 노드로 표시되어 리팩터링 우선순위를 알려줍니다.

읽기/쓰기 관계 색상 구분
순환 참조 위험 노드 표시
필터로 관계 켜고 끄며 탐색

찾고 싶은 로직을 문장으로 검색

“주문 배송 요청에서 택배사를 선택하고 배송 정보를 저장한 뒤 상태를 갱신하고 문자를 보내는 처리”처럼 자연어 문장을 그대로 입력하면 의미가 가장 가까운 노드를 찾아줍니다.

자연어 문장으로 의미 기반 검색
관련도 순위별 후보 노드 제시
논리명·원문 이름 전환 표시

한 문장이 호출 사슬 전체를 짚어낸다

검색된 노드를 클릭하면 택배사 선택 → 배송 정보 갱신 → 추적 이력 생성 → 배송 문자 발송으로 이어지는 실제 호출 순서를 코드와 함께 그대로 보여줍니다.

호출 순서대로 함수 체인 시각화
코드 본문과 그래프 동시 확인
자연어 검색과 그래프 탐색 연동

Robo Architect와의 연결

그래프 분석이 그대로 전환 설계가 됩니다

Legacy Analyzer가 그린 호출·읽기/쓰기 관계 그래프와 자연어 검색 결과는 Robo Architect의 프로포절(Proposal) 파이프라인으로 그대로 이어집니다. 분석 대상 중 원하는 마이크로서비스(예: 주문·재고)만 골라 프로포절을 생성하면, Plan 단계에서 Aggregate·Command·Event가 자동으로 도출되고 샌드박스에서 DDD 코드로 구현되어 검증까지 마친 뒤 실제로 동작하는 서비스로 완성됩니다.

레거시를 이해하는 것과 새 아키텍처로 바꾸는 것은 원래 하나의 흐름입니다. Legacy Analyzer는 그 출발점이며, 도메인 설계·프로포절 라이프사이클·Claude Code 기반 구현과 검증까지 이어지는 전체 그림은 Robo Architect에서 확인하실 수 있습니다.

분석 그래프 → 프로포절 자동 생성 (전환 대상만 선택)
Plan 단계에서 Aggregate·Command·Event 자동 도출
샌드박스 구현 → 검증 → Dual Merge로 실제 서비스 완성

동작 방식

레거시 코드가 실행 가능한 마이크로서비스가 되기까지, Robo Legacy Analyzer는 다음 흐름으로 동작합니다

1. 연결 & 업로드

DB에 연결하고 소스코드·DDL을 업로드해 분석 대상을 등록합니다.

2. 그래프 자동 분석

DDL 파싱, AST 로딩, 관계 추론, 클러스터링까지 자동으로 처리합니다.

3. 탐색 & 자연어 검색

필터·색상·논리명으로 탐색하고 문장 하나로 로직과 호출 사슬을 찾습니다.

4. Robo Architect로 전환

분석 그래프가 프로포절 입력이 되어 DDD 마이크로서비스로 자동 구현됩니다.

비교표 요약

특성 Robo Legacy Analyzer 수동 리버스 엔지니어링
분석 대상 파악호출·읽기/쓰기 관계를 그래프로 자동 시각화문서·주석에 의존한 수작업 추적
위험 신호 식별순환 참조·쓰기 편중을 색상으로 즉시 표시코드 리뷰 중 뒤늦게 발견
로직 검색자연어 문장으로 의미 기반 검색파일명·변수명 추측 후 grep
협력 관계 파악클러스터 자동 탐지·명명팀 경험에 의존한 암묵지
전환 설계분석 결과가 Robo Architect 프로포절로 즉시 연결별도 문서로 재작성 필요
산출물DDD 기반 마이크로서비스 코드 자동 구현·검증수동 재구현 후 별도 테스트
