uEngine MES

모든 변경을 이벤트로 기록하는 제조 실행 시스템 — 설비가 멈추면 영향을 계산하고, 판단과 실행의 근거를 남기며, AI 에이전트가 사람의 승인 아래 대응합니다

시연 영상튜토리얼문의하기

시연용 참조 구현입니다. 소스는 공개하지 않고, 화면의 회사·제품·수치는 모두 합성 데이터입니다. 시연 환경은 문의해 주세요. uEngine MES는 이벤트 소싱으로 구현했지만 사람이 쓰는 되돌리기 화면은 없으며, 소스는 비공개이므로 시연 환경은 문의하세요.

기록하는 MES에서, 판단하고 대응하는 MES로

현재 상태만 저장하면 왜 그렇게 됐는지가 남지 않습니다. uEngine MES는 모든 변경을 이벤트로 저장합니다. 설비가 멈추면 어떤 작업지시와 수주, 납기가 영향을 받는지 계산하고, 담당자의 판단과 실행 결과가 같은 이력에 이어집니다.

그 위에 Process GPT 에이전트와 시맨틱 레이어를 연결했습니다. 에이전트는 여러 시스템의 근거를 모아 대안을 내고, 사람이 결정하면 실행한 뒤 원천을 다시 읽어 확인합니다. 사람이 「앞으로 적용」이라고 정한 결정은 규칙의 새 버전이 되어, 같은 이상이 또 생기면 다시 결정하지 않아도 처리됩니다.

현장 대응에서 AI 연결까지

모두 실제로 실행해 찍은 화면입니다. 화면을 누르면 그 장의 영상이 재생됩니다.

현장 대응

설비가 멈추면, 영향부터 계산합니다

정지를 등록하면 이상 상황이 열리고, 영향 범위와 대체 설비 후보가 바로 나옵니다.

  • 영향 분석설비와 작업지시, 수주, 납기의 관계를 따라가며 잔량과 최단 납기를 계산합니다.
  • 사람이 고르는 대응사유와 승인자를 기록하고 보류와 대체 설비 재계획을 실행합니다.
  • 대응 지표영향 분석, 대응, 재계획, 복구 시간과 손실 수량을 이벤트 시각을 기준으로 계산합니다.
▶ 1장 설비 이상 대응

이력과 추적

왜 그렇게 됐는지, 이벤트로 되짚습니다

여러 서비스에 걸친 원인과 결과가 그대로 남고, 그때의 공장 상태도 다시 볼 수 있습니다.

  • 변경 이력화면마다 필드별 변경 전후와 사유, 승인자를 봅니다.
  • 프로세스 추적상관 ID로 묶인 이벤트를 서비스 레인과 인과 화살표로 펼칩니다.
  • 시점 조회 · 재구축그때의 설비 상태를 재생으로 복원하고, 읽기 모델을 이벤트로 다시 만듭니다.
▶ 2장 이벤트 추적

AI 연결

흩어진 시스템을 하나의 판단으로 묶습니다

「오늘 17시까지 2,000개 납품할 수 있나?」처럼 어느 시스템도 단독으로 답하지 못하는 질문에 LOT별 근거와 함께 답합니다.

  • 원천은 그대로ERP, SCM, APS, MMS, QMS, MES, Edge 7종의 데이터를 복제하지 않고 질의할 때 읽습니다.
  • 판단 개념출하 가능 수량처럼 어느 시스템에도 없는 개념을 규칙과 함께 정의합니다.
  • 함수와 회귀기존 프로시저와 서비스를 read·plan·exec 함수로 등록하고, Golden Question으로 다시 검증합니다.
▶ 3장 시맨틱 레이어

AI 연결

에이전트가 제안하고, 사람이 결정하고, 규칙으로 배웁니다

용접 이상 한 건을 부서별 에이전트가 넘겨받아 처리합니다. 사람은 결정 카드에서 고르기만 합니다.

  • 부서별 에이전트위험 판정, 의심 LOT 추적, 납기 영향, 대안 시뮬레이션을 차례로 맡습니다.
  • 실행과 재조회승인된 결정으로만 실행하고, 쓰기마다 원천을 다시 읽어 확인합니다.
  • 재발 시 자동 처리「앞으로 적용」한 결정은 규칙의 새 버전이 되어 다음 사건이 발생하면 조건을 확인해 자동으로 실행합니다.
▶ 4장 에이전트 협업과 사람의 결정

구성과 현재 상태

구현된 기능과 아직 구현되지 않은 기능을 그대로 적었습니다.

구분내용
백엔드업무 서비스 10개와 게이트웨이. Java 17, Spring Boot, Kafka, PostgreSQL
화면Vue 3. 대메뉴 9개, 중메뉴 60개, 화면 145개. 대부분 범용 그리드 화면이고 생산·설비·품질·창고 등 핵심 화면은 전용으로 만들었습니다
이벤트 소싱추가만 되는 이벤트 저장소, 아웃박스, 상관·인과 ID, 시점 조회, 프로젝션 재구축
AI 연결Process GPT 프로세스와 에이전트, 시맨틱 레이어, read·plan·exec 함수, 사람의 결정 카드
아직 없는 것범용 화면에는 도메인 규칙이 없습니다. 권한 데이터는 메뉴·API 접근 제어에 아직 쓰이지 않습니다. 컨테이너 이미지가 없습니다. 시맨틱 레이어와 데이터 패브릭은 시연용 경량 구현이고, 비전 추론은 학습된 모델이 아니라 픽셀 규칙으로 흉내 낸 것입니다
