업무 자동화 (RPA)

uEngine RPA

반복 업무를 말로 설명하면 AI가 자동화를 만들고, 그다음부터는 AI 비용 없이 로봇이 매일 대신 처리합니다

GitHub 데모 영상 보기

만들 때는 AI와 함께, 돌릴 때는 비용 없이

uEngine RPA는 엑셀 정리, 사내 시스템 입력, 보고서 취합, 메일 발송처럼 사람이 매일 반복하는 컴퓨터 업무를 로봇에게 맡기는 도구입니다.

자동화를 만드는 일은 AI에게 말로 시키고, 완성된 자동화는 정해진 순서대로 돌아가는 로봇이 실행합니다. 그래서 AI 비용은 만들 때 한 번만 들고, 실행은 몇 번을 해도 무료이며 결과는 매번 같습니다.

만들어진 자동화는 uEngine BPM 프로세스의 한 단계로 연결되어, 사람의 업무와 로봇의 업무가 하나의 흐름 안에서 함께 돌아갑니다.

주요 기능

말로 설명하면 AI가 자동화를 만들어 줍니다

"주문서 엑셀을 열어 금액이 100만 원 넘는 건만 골라 사내 시스템에 등록해 줘"처럼 평소 업무를 설명하듯 적으면 됩니다. AI가 필요한 단계를 골라 자동화 흐름을 만들어 캔버스에 그려 줍니다.

업무를 한국어로 설명하면 끝
만드는 과정이 화면에 실시간으로 표시
마음에 안 들면 한 번에 되돌리기

만든 뒤에는 AI 비용이 들지 않습니다

AI는 자동화를 만들 때 한 번만 씁니다. 완성된 자동화는 로봇이 정해진 순서대로 실행할 뿐이라, 매일 수백 번을 돌려도 추가 AI 비용이 없고 결과도 매번 같습니다.

AI 비용은 만들 때 한 번, 실행은 무료
실행할 때마다 같은 결과 — 재현 가능
인터넷·외부 AI 없이도 사내에서 실행

바로 쓰는 자동화 부품 550개

웹 브라우저 조작, 엑셀 편집, PDF 처리, 파일 정리, 이메일 발송, 윈도우 프로그램 제어까지 18개 분야 550개의 자동화 부품이 준비되어 있습니다. 이름으로 찾아 끌어다 놓기만 하면 됩니다.

입력값은 블록 안에서 바로 채웁니다

블록 안에서 직접 입력 · 켜고 끄기

조건 · 반복 · 예외도 블록으로

"이 조건이면 이렇게, 아니면 저렇게", "목록을 하나씩 돌면서", "실패하면 이렇게 수습" 같은 흐름을 블록으로 표현합니다. 블록 안에 블록을 넣어도 화면이 옆으로 끝없이 늘어나지 않아 복잡한 업무도 한눈에 읽힙니다.

조건 분기 · 반복 · 예외 처리 · 묶음
블록 안에 블록을 넣는 중첩 표현
넣을 자리를 파란 선으로 안내

값을 이름 붙여 두고 어디서나 재사용

사내 시스템 주소, 처리할 파일 목록, 담당자별 이메일 같은 값을 한 번 이름 붙여 두면 어느 블록에서든 $ 버튼으로 골라 씁니다. 값이 바뀌어도 한 곳만 고치면 됩니다.

단일값 · 목록 · 사전 · 환경변수
$ 버튼으로 어느 입력란에나 삽입
한 곳만 고치면 전체에 반영

큰 자동화도 길을 잃지 않게

블록을 더블클릭하면 그 부품의 설명과 입력값 안내가 옆에 열립니다. 확대·축소 도구와 미니맵, 블록 종류별 색상 범례로 단계가 수십 개인 자동화도 한 화면에서 다룹니다.

블록별 설명 · 입력값 안내
확대 · 축소 · 미니맵
종류별 색상으로 구분

반복되는 절차는 나만의 부품으로

"사내 포털 로그인"처럼 여러 자동화에서 반복되는 절차는 하나의 부품으로 묶어 두고 재사용합니다. 한 번 잘 만들어 두면 팀 전체가 같은 부품을 가져다 씁니다.

자주 쓰는 절차를 부품으로 저장
여러 자동화에서 재사용
부품만 고치면 쓰는 곳 모두 반영

무엇이 실행될지 항상 투명하게

캔버스 옆에서 실제 실행 내용을 글로도 확인할 수 있습니다. 업계 표준 형식의 텍스트라 형상관리 도구로 변경 이력을 남기고, 동료가 검토하고, 다른 도구로 가져갈 수도 있습니다.

캔버스와 실행 내용이 항상 일치
변경 이력 · 동료 검토 가능
특정 제품에 묶이지 않는 표준 형식

회사 정책에 맞는 AI를 골라 씁니다

자동화를 만들 때 쓰는 AI는 내 컴퓨터에 설치된 것을 사용합니다. Claude Code, Codex 등 쓸 수 있는 AI를 자동으로 찾아 주고, 모델러가 업무 내용을 외부로 보내지 않습니다.

설치된 AI 자동 탐지 · 선택

업무 흐름을 표현하는 블록

단순 나열을 넘어 조건·반복·예외까지 블록으로 그립니다. 블록 안에 블록을 넣어 실제 업무 규칙을 그대로 옮깁니다.

조건 분기

IF · ELSE IF · ELSE

"금액이 100만 원을 넘으면 승인 요청, 아니면 자동 등록"처럼 조건에 따라 다른 길로 보냅니다. 조건은 여러 개를 AND/OR로 묶을 수 있습니다.

반복

FOR · WHILE

엑셀 행마다, 파일마다, 1부터 100까지, 두 목록을 나란히 — 네 가지 방식으로 반복합니다. WHILE은 "파일이 도착할 때까지"처럼 조건이 참인 동안 돌고, 최대 횟수 제한으로 무한 반복을 막습니다.

예외 처리

TRY · EXCEPT · ELSE · FINALLY

사이트가 느리거나 파일이 없을 때 로봇이 멈추지 않고 수습합니다. 오류 종류별로 다른 대응을 두고, 성공하든 실패하든 마지막에 할 일(창 닫기 등)을 지정합니다.

흐름 제어

BREAK · CONTINUE · RETURN

찾던 것을 발견하면 반복을 바로 끝내고(BREAK), 해당 건만 건너뛰거나(CONTINUE), 결과를 돌려주며 끝냅니다(RETURN).

묶음

GROUP

관련된 여러 단계를 하나의 이름으로 묶어 실행 기록에서 한 덩어리로 읽히게 합니다.

이렇게 씁니다

업무 하나를 맡기는 데 네 단계면 충분합니다

1. 업무를 설명합니다

"매주 월요일 지점별 매출 엑셀을 모아 합계표를 만들고 팀장에게 메일로 보내 줘"처럼 평소 말로 적습니다.

2. AI가 초안을 그립니다

필요한 부품을 골라 순서대로 이은 자동화 초안이 캔버스에 나타납니다. 블록을 보며 빠진 단계를 끌어다 넣고 값을 다듬습니다.

3. 실행해 봅니다

실행 버튼을 누르면 로봇이 바로 움직이고 진행 상황이 화면 아래에 표시됩니다. 막히는 곳은 블록에서 값을 고쳐 다시 돌립니다.

4. 맡기고 잊습니다

저장한 자동화는 예약 실행하거나 uEngine BPM 프로세스의 한 단계로 붙입니다. 이후로는 AI 비용 없이 로봇이 반복합니다.

AI 비용은 만들 때 한 번, 실행은 무료

AI에게 매번 업무를 시키는 방식과 가장 다른 점입니다. AI는 자동화를 설계할 때만 쓰고, 실제 업무는 로봇이 처리합니다.

만들 때 · 한 번

AI와 함께 설계

업무를 설명하면 AI가 자동화를 그려 줍니다. 이때만 AI를 씁니다. 수정할 때도 마찬가지로 한 번입니다.

돌릴 때 · 매일

로봇이 반복 실행

완성된 자동화는 정해진 순서대로 로봇이 실행합니다. AI 호출이 없으니 비용도, 답변이 달라질 걱정도 없습니다.

예측 가능한 비용. 하루 천 번을 돌려도 AI 사용료가 늘지 않습니다.
같은 입력, 같은 결과. 감사·규제 대응이 필요한 업무에도 안심하고 씁니다.
외부 연결 없이 실행. 인터넷이 막힌 망에서도 로봇은 그대로 돕니다. 설계에 쓰는 AI도 회사가 허용한 것만 고릅니다.

uEngine BPM과 하나의 흐름으로

로봇 혼자 도는 자동화로 끝나지 않습니다. uEngine RPA로 만든 자동화는 uEngine BPM 프로세스의 한 단계(스크립트 태스크)로 붙어, 사람이 하는 일과 로봇이 하는 일이 하나의 업무 흐름 안에서 순서대로 이어집니다.

→
사람팀장 승인비교표를 보고 결재합니다
→
로봇 · uEngine RPAERP 발주 등록승인된 내용을 ERP 화면에 입력하고 결과를 회신

프로세스 안의 로봇 단계

BPM 프로세스 모델에서 로봇이 할 단계를 스크립트 태스크로 두고 uEngine RPA 자동화를 지정합니다. 차례가 오면 BPM이 로봇을 깨우고, 결과를 받아 다음 단계로 넘깁니다.

데이터가 그대로 흐릅니다

앞 단계에서 사람이 입력한 값이 로봇의 변수로 전달되고, 로봇이 만든 결과(파일·표·상태)가 다음 사람의 화면에 나타납니다. 따로 옮겨 붙일 일이 없습니다.

한 곳에서 관리하고 추적

누가 언제 무엇을 했고 로봇이 어디까지 처리했는지 BPM의 업무 이력에 함께 남습니다. 로봇이 실패하면 담당자에게 업무로 되돌려 사람이 이어받습니다.
