uEngine WMS

재고 부족에서 입고·검수·적치, 창고 설비 제어까지 — Process GPT 에이전트가 도구로 쓰도록 만든 창고 관리 샘플

시연 영상튜토리얼GitHub

Process GPT 샘플 앱입니다. 소스는 공개되어 있고 데모 규모로 만들었습니다. 튜토리얼은 새로 설치되는 것을 확인한 커밋 fc82ea2 기준입니다. uEngine WMS는 이벤트 소싱이 아니라 값을 저장하고 모든 쓰기를 감사 로그에 남기는 방식이며, 되돌리기 기능은 없습니다.

에이전트가 실제로 쓸 수 있는 창고 시스템

재고가 모자라면 구매 요청과 승인, 발주, 입고, 품질 검사, 적치까지 이어집니다. uEngine WMS는 이 흐름과 창고 설비 제어를 한 앱에서 보여 주는 Process GPT 샘플 앱입니다. 역할마다 할 수 있는 일이 다르고, 모든 데이터 쓰기가 감사 로그에 남습니다.

기능을 MCP 도구로 제공하므로 Process GPT 에이전트도 같은 권한 검사를 받으며 사용합니다. 재보충 프로세스를 실제 LLM 에이전트로 실행하면 에이전트가 재고를 읽고 구매 요청을 만들며, 승인과 품질 판정은 사람이 합니다.

입고에서 설비, 에이전트까지

공개 저장소의 앱을 실제로 실행해 찍은 화면입니다. 화면을 누르면 그 장의 영상이 재생됩니다.

입고와 재고

재고가 부족한 품목 하나를 적치까지 따라갑니다

역할을 바꿔 가며 처리하고, 단계마다 문서 상태와 감사 로그가 남습니다.

  • 구매 흐름재고 부족에서 RFQ, 승인, PO 확정까지 이어집니다.
  • 입고와 품질도착과 입고를 등록하고, 합격이면 적치, 불합격이면 폐기합니다.
  • 역할과 격리같은 문서도 역할에 따라 보이는 버튼이 다르고, 테넌트는 행 수준 보안으로 나뉩니다.
▶ 1장 재보충에서 적치까지

창고 자동화

업무 오더를 설비 명령으로 내보냅니다

웨이브로 묶어 내보내면 대기 중인 설비로 명령이 나갑니다. 실제 설비 대신 게이트웨이 계정과 시뮬레이터가 응답합니다.

  • 작업 지시입고 건을 업무 오더로 만들고, 웨이브 또는 즉시 디스패치로 내보냅니다.
  • 설비 제어설비 등록, 명령, 상태 보고를 다룹니다. 장애 해소는 사람만 할 수 있습니다.
  • 분류와 병목분류기 프로파일과 잼 장애, 임계값 기반 병목 감지와 회피를 봅니다.
▶ 2장 작업 지시와 설비 제어

창고 자동화

서열대로 묶어 로봇 셀로 보냅니다

매장별 출고 단위를 서열대로 팔레트에 묶고, 시뮬레이터 워커의 응답과 실패 경로까지 확인합니다.

  • 서열 배정위치와 무게를 사람이 정한 값으로 검증해 팔레트로 묶습니다.
  • 시뮬레이션실제 설비 없이 워커가 접수, 진행, 완료, 실패를 보고합니다.
  • 가정 시나리오설비 수와 명령 수를 바꿔 낙관적 추정치를 봅니다. 추정의 한계도 함께 나옵니다.
▶ 3장 서열 출고와 시뮬레이션

AI 연결

에이전트가 도구를 쓰고, 사람이 승인합니다

재보충 프로세스를 실제 LLM 에이전트로 끝까지 실행했습니다. 사람은 시작과 구매 승인, 품질 판정을 맡습니다.

  • MCP 도구 83개앱의 데이터베이스 함수를 도구로 제공합니다. 에이전트 계정도 역할 검사를 받습니다.
  • 제안 검토에이전트가 낸 제안은 창고 관리자가 승인하거나 반려합니다. 자기 제안은 승인할 수 없습니다.
  • 감사 로그사람과 에이전트의 데이터 쓰기를 같은 이력에서 문장으로 읽습니다.
▶ 4장 Process GPT 에이전트 연동

개발 중

디지털 트윈: 도면 위에서 설비 상태를 봅니다

아직 공개 저장소에 포함되지 않은 개발 중인 화면입니다. 튜토리얼에서는 다루지 않고 제품 시연 영상에서 보여 드립니다.

  • 실시간 도면구역 위에 설비와 하역장이 현재 상태를 나타내는 색으로 표시됩니다.
  • 장애 대응장애가 보고되면 새로 고치지 않아도 알람이 뜨고, 이 화면에서 바로 해소합니다.
  • 병목·가정 렌즈설비별 큐와 임계값, 추정치와 그 한계를 함께 봅니다.
▶ 제품 시연에서 보기

구성과 현재 상태

구현된 기능과 아직 구현되지 않은 기능을 그대로 적었습니다.

구분내용 (커밋 fc82ea2 기준)
화면업무 화면 17개. 버튼과 표 머리글은 영어, 설명은 한국어입니다
데이터Supabase(Postgres, 인증, 행 수준 보안). 테이블 37개, 함수 115개, RLS 정책 35개, 역할 10개
에이전트 연결FastMCP 서버와 MCP 도구 83개, Process GPT 설치 스크립트
검증Playwright E2E 시험 12개
아직 없는 것실제 설비에 연결하지 않고 시뮬레이터로 시연합니다. 출고가 재고를 차감하지 않습니다. 재보충 프로세스는 끝까지 실행되지만 인스턴스 표시는 실행 중으로 남습니다. 설치 스크립트에 보정 스크립트를 더해야 끝까지 실행됩니다. 저장소의 최신 main은 새로 설치하면 실패해 튜토리얼은 fc82ea2로 고정합니다

영상으로 보기

공개 저장소의 앱을 실제로 실행하며 녹화한 영상입니다. 썸네일을 누르면 재생됩니다.

1장 재보충에서 적치까지

RFQ, 승인, PO, 입고, 품질, 적치와 불합격 폐기를 따라갑니다.

2장 작업 지시와 설비 제어

설비 명령, 장애, 웨이브, 분류기, 병목 회피를 봅니다.

3장 서열 출고와 시뮬레이션

팔레타이징, 시뮬레이터 워커, 가정 시나리오를 봅니다.

4장 Process GPT 에이전트 연동

MCP 도구, 재보충 프로세스, 제안 검토, 감사 로그까지 실제로 실행합니다.
