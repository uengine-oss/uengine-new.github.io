# 한 장 요약

> 이 튜토리얼에서 쓴 말과 버튼을 일의 종류별로 한곳에 모았습니다. 문장은 예시일 뿐이니 그대로 외울 필요는 없습니다. 무엇을, 어떤 모양으로 원하는지만 분명하면 비서가 알아듣습니다.

|---|---|

## 잘 시키는 다섯 가지

1. **재료를 함께** — 원문, 파일, 숫자를 붙여 주면 지어내지 않습니다.
2. **모양을 말하기** — 표로, 체크리스트로, 엑셀로, 파일 이름은 ….
3. **첫 문장에 이름을** — “달빛커피 …”처럼 고객·행사 이름을 앞에 두면 대화가 잘 나뉘고 목록에서 찾기 쉽습니다.
4. **나눠서** — 정리 → 확인 → 파일 → 공유. 중간에 바로잡기 쉽습니다.
5. **위험한 일은 승인 받게** — 결제·발송·삭제 전에는 “나에게 먼저 물어봐”를 붙입니다.

설치·비용·보안처럼 따라 하다 생기는 질문은 다음 장에 모았습니다([28장](faq.html)).

!!! exercise "확인 문제"
    1. 장진영 팀장이 공유한 견적서를 박서연이 받아 자기 비서에게 검토를 맡기려면 어디를 누르나요?
    2. 정식 프로세스에서 내 차례가 된 단계는 어디에 어떤 모양으로 뜨나요?
    3. 비서에게 결제나 메일 발송처럼 되돌리기 어려운 일을 시킬 때, 지시에 무엇을 붙이면 좋을까요?

<details class="answer" markdown="1"><summary>답</summary>

1. 박서연 계정에서 오른쪽 위 「메시지」 › 「받은 편지함」의 그 공유에서 「이어서 작업」을 누릅니다(14장).
2. 홈에 「결정」 또는 「입력」 카드로 뜹니다. 결재처럼 선택지가 있으면 카드에서 바로 고를 수 있습니다(18장).
3. “결제 버튼을 누르기 전에 꼭 나에게 승인을 받아”처럼, 그 동작 전에 먼저 나에게 묻게 하는 말을 붙입니다(잘 시키는 다섯 가지의 5번).
</details>
