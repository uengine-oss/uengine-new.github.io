# 설정 — 동료를 들이고 화면을 바꾸기

> 위쪽 막대의 ⚙ 설정에서 내 계정과 테마를 바꾸고, 영업 담당 김민지를 이 회사의 사용자로 들입니다. 화면 언어를 영어로 바꿨다가 되돌려 보고, 지식 베이스 탭과 [14장](mcp-hub.html)에서 쓸 MCP 서버·환경변수 탭이 어디 있는지 확인합니다.

## 설정 화면

위쪽 막대 오른쪽 끝의 ⚙을 누르면 설정이 열립니다. 위에 탭이 한 줄로 있고, 줄 끝에 화면 언어(「🇰🇷 한국어」)가 있습니다.

| 탭 | 하는 일 | 이 튜토리얼 |
|---|---|---|
| 계정 설정 | 이름·이메일·프로필 사진, 2단계 인증(OTP) | 이 장 |
| 테마 설정 | 색상 테마(라이트·스카이·다크), 화면 간소화, 휴대폰 화면(휴대폰에서만), 홈 화면에 추가 | 이 장 · [2장](tour.html) |
| 사용자 관리 | 같은 회사 사람 목록과 역할 | 이 장 |
| 지식 베이스 | 위쪽 막대의 지식 베이스와 같은 화면 | [8장](knowledge.html) |
| MCP 서버 · 환경변수 | 에이전트에게 붙일 도구 서버와 그 비밀값 | [14장](mcp-hub.html) |
| CLI 에이전트 API 키 | Claude Code · Codex CLI 가 쓸 회사 API 키(관리자만) | 이 장 |
| 구글 드라이브 설정 · Git 설정 · 데이터소스 · 코드 편집 · 용어집 관리 · 카탈로그 · 조직 그룹 · 테넌트 관리 | 바깥 저장소·데이터 연동과 관리 기능 | 쓰지 않음 |

![설정 — 계정 설정 탭(프로필 이미지, 이름·이메일, 2단계 인증), 탭 줄 끝의 「🇰🇷 한국어」](img/set-account.webp)

## 따라 하기 1 — 계정과 테마

<ol class="steps" markdown="1">
<li markdown="1">「계정 설정」에서 이름과 프로필 사진을 바꿀 수 있습니다. 바꾸면 「저장」을 누릅니다.</li>
<li markdown="1">「2단계 인증 (OTP)」의 「2단계 인증 사용」을 켜면 로그인할 때마다 인증 앱의 6자리 코드를 한 번 더 넣습니다. 실습에서는 켜지 않습니다.</li>
<li markdown="1">「테마 설정」에서 색상 테마를 골라 봅니다. 「화면 간소화」를 켜면 정의 체계도와 인스턴스 화면이 목록 · 대화 · 산출물 세 칸으로만 보입니다.</li>
<li markdown="1">휴대폰 브라우저로 설정을 열면 「테마 설정」에 「휴대폰 화면」이 추가로 보입니다. 「데스크톱 버전」과 「라이트 버전」 중 하나를 고르면 화면이 새로 열리며 바로 바뀝니다. 「홈 화면에 추가」로 휴대폰 홈 화면에 아이콘을 만들 수 있습니다([2장](tour.html)).</li>
</ol>

![테마 설정 — 색상 테마 라이트·스카이·다크, 화면 간소화](img/set-theme.webp)

## 따라 하기 2 — 동료 들이기

!!! note "5장을 했다면"
    [5장](organization.html)에서 김민지·박서연을 먼저 가입시켰다면 「사용자 관리」에 세 사람이 「소속 팀 : 영업팀」과 함께 보입니다. 아래는 그때 한 방법(같은 주소에서 직접 가입)을 다시 정리한 것이니 건너뛰어도 됩니다.

「사용자 관리」에는 지금 나(장진영, superAdmin) 한 사람만 있습니다. 「사용자 초대」는 초대 메일을 보내는 기능인데, 로컬 설치본은 메일을 보내지 않습니다. 로컬에서는 동료가 **같은 주소에서 직접 가입**하면 이 회사의 사용자로 들어옵니다.

![사용자 관리 — 「사용자 초대」 단추와 장진영(나, superAdmin)](img/set-users.webp)

<ol class="steps" markdown="1">
<li markdown="1">다른 브라우저(또는 시크릿 창)로 http://localhost:8088 을 열고 「시작하기」 › 「계정 생성」으로 영업 담당 **김민지**(`minji@hanbit.example`)를 가입시킵니다([1장](install.html)과 같습니다).</li>
<li markdown="1">“회원가입에 성공했습니다”와 함께 김민지로 바로 로그인되어 홈이 열립니다.</li>
<li markdown="1">장진영 쪽 「사용자 관리」를 새로고침하면 김민지(`user`)가 목록에 들어와 있습니다.</li>
</ol>

![김민지 가입 — 계정 생성 화면](img/in-minji-register.webp)

![가입 뒤 사용자 관리 — 장진영(superAdmin)과 김민지](img/set-users-after.webp)

!!! note "처음 가입한 사람만 관리자"
    로컬 설치본은 회사 하나(테넌트 `localhost`)만 둡니다. 처음 가입한 사람이 관리자(superAdmin), 그 뒤에 가입한 사람은 일반 사용자(user)로 바로 들어옵니다.

## 따라 하기 3 — 화면 언어 바꾸기

<ol class="steps" markdown="1">
<li markdown="1">탭 줄 끝의 「🇰🇷 한국어」를 누르고 **🇺🇸 English**를 고릅니다. 탭 이름이 Account Settings, Appearance, Manage Users …로 바뀝니다.</li>
<li markdown="1">홈으로 가 보면 사이드바(Conversations, Agent Colleagues)와 채팅 상자(「How can I help you?」, Deep Agent)도 영어입니다. 내가 만든 프로세스·에이전트 이름은 그대로입니다.</li>
<li markdown="1">다시 설정의 「English」를 눌러 **한국어**로 되돌립니다.</li>
</ol>

## 따라 하기 4 — CLI 에이전트 API 키 (관리자)

Claude Code · Codex 같은 CLI 에이전트가 업무와 채팅을 처리할 때 쓰는 **회사의 API 키**를 입력하는 곳입니다. 관리자에게만 보입니다.
개인 구독 토큰을 여러 사람이 나눠 쓰면 약관 위반이므로, 회사가 Claude Console(Anthropic) · OpenAI 플랫폼에서 직접 발급한 키를 입력합니다.

<ol class="steps" markdown="1">
<li markdown="1">설정 화면의 탭 목록에서 **CLI 에이전트 API 키**를 엽니다. Claude Code(Anthropic API 키)와 Codex(OpenAI API 키) 두 칸이 「설정 안 됨」으로 보입니다.</li>
<li markdown="1">회사 키를 「새 키 붙여 넣기」에 붙여 넣고 **저장**을 누릅니다. 칸이 비워지고 상태가 「설정됨 · ••••끝 네 자리 · 이름 · 시각」으로 바뀝니다. 입력한 키는 다시 보여 주지 않습니다.</li>
<li markdown="1">키를 입력한 CLI는 새 대화의 에이전트 선택에서 **CLI 코딩 에이전트**로 고를 수 있습니다. 키가 없는 CLI는 채팅에서 고를 수 없고, 업무는 지금처럼 서버에 설정된 자격 증명으로 실행됩니다.</li>
</ol>

![설정 — CLI 에이전트 API 키 탭(Claude Code · Codex, 회사 키 안내)](img/set-cli-keys.webp)

!!! note "「키 저장소가 준비되지 않았습니다」가 보이면"
    키는 데이터베이스의 암호화 저장소(Supabase Vault)에 저장합니다. 운영 서버에 해당 설정이 아직 적용되지 않았다면 이 안내가 보이고 키를 넣을 수 없습니다. 운영 관리자가 DB 설정을 적용하면 바로 사용할 수 있습니다.
