# Robo Architect 튜토리얼

> 요구사항 한 줄을 프로포절로 만들어 도메인 주도 설계(DDD)로 나누고, 프로젝트 헌장과 계획을 세워 Claude Code가 샌드박스에서 구현하게 한 뒤, 인수 조건으로 검증하고 설계에 되돌려 반영하는 흐름을 Robo Architect Lite 데스크톱 앱에서 처음부터 한 단계씩 익히는 실습서입니다.

## Robo Architect는

Robo Architect는 **명세 주도 개발(Spec-Driven Development) 도구**입니다. 코드가 아니라 명세(Spec)를 원본으로 삼습니다. 요구사항을 자연어로 쓰면 AI가 도메인 주도 설계(DDD)의 말로 나눕니다 — 바운디드 컨텍스트, 애그리거트, 커맨드, 이벤트, 그리고 Given-When-Then 형식의 인수 조건입니다. 그 설계를 근거로 Claude Code가 코드를 쓰고, 다 쓴 코드는 다시 설계와 대조해 검증합니다.

모든 변경은 **프로포절** 하나로 다룹니다. 프로포절은 다음 순서로 나아갑니다.

| 단계 | 하는 일 | 이 튜토리얼 |
|---|---|---|
| INTENT | 자연어 요구사항을 전략 설계(프로세스·바운디드 컨텍스트·기능·유저 스토리·인수 조건)로 나눕니다 | 3장 |
| PLAN | 프로젝트 헌장을 근거로 전술 설계와 아키텍처, 영향도를 정합니다 | 4·5장 |
| IMPLEMENTING | 별도의 Git 워크트리(샌드박스)에서 Claude Code가 구현합니다 | 6장 |
| VALIDATING · 승인 대기 | 구조 검증과 인수 조건 테스트를 돌립니다 | 7장 |
| ACCEPTED | 수락하면 코드가 본체에 합쳐지고 설계 그래프에 반영됩니다 | 7장 |

이 튜토리얼은 **Robo Architect Lite**를 씁니다. Lite는 내 컴퓨터에서 혼자 쓰는 데스크톱 앱입니다. 설계는 Neo4j가 아니라 **Ontological DB**의 그래프에 저장하고, 프로젝트마다 그래프가 하나씩 생깁니다. 로그인 화면이 없고, AI 작업은 내 컴퓨터의 Claude Code가 맡습니다.

## 이 튜토리얼의 이야기

동네 음식점과 고객을 잇는 배달 서비스 **한빛 딜리버리**를 만듭니다. 여러분은 이 서비스의 설계를 맡은 **장진영**입니다.

| 등장 | 역할 |
|---|---|
| 장진영 | 한빛 딜리버리의 아키텍트. 이 튜토리얼에서 여러분이 맡는 사람입니다 |
| 사장님 | 가게 메뉴를 등록하고 들어온 주문을 접수합니다 |
| 고객 | 메뉴를 골라 주문하고, 접수 전이면 취소합니다 |
| Claude Code | 스킬을 따라 설계를 나누고, 계획을 세우고, 코드를 쓰는 AI 동료 |

1. **시작하기** — 앱을 설치해 첫 프로젝트를 만들고 화면을 둘러봅니다.
2. **프로포절 라이프사이클** — 「메뉴 등록과 주문」 요구사항을 프로포절로 만들어 전략 설계를 받고, 프로젝트 헌장을 정해 계획을 세운 뒤, 샌드박스에서 구현하고 검증해 수락합니다.
3. **설계와 변경** — 수락된 설계를 Stories·Process·Design·Data 탭에서 보고, 두 번째 요구사항이 기존 설계에 주는 영향을 영향도 맵으로 읽고, 엔진의 스킬 파일을 들여다봅니다.
4. **레거시와 데이터** — 한빛 딜리버리의 기존 주문 DB를 데이터 소스로 붙여 스키마를 봅니다.
5. **마무리** — 리뷰 기능을 처음부터 끝까지 직접 넣는 종합 과제입니다.

## 누구를 위한 튜토리얼인가

- 웹 서비스를 한 번쯤 만들어 본 개발자, 또는 요구사항과 설계를 다루는 기획자·아키텍트가 대상입니다.
- DDD를 몰라도 됩니다. 바운디드 컨텍스트·애그리거트 같은 말은 처음 나올 때 장 안에서 설명합니다.
- 코드를 직접 쓰지 않습니다. 코드는 Claude Code가 씁니다. 여러분은 설계를 읽고 고르고 확인합니다.

## 준비물

| 항목 | 내용 |
|---|---|
| 컴퓨터 | macOS 또는 Windows 10/11. 메모리 16GB 이상, 디스크 여유 20GB 이상 |
| Docker Desktop | 그래프 DB와 분석 서비스가 컨테이너로 돕니다. 켜져 있어야 합니다 |
| Claude Code | 터미널에서 `claude` 가 실행되고 로그인되어 있어야 합니다. 프로포절의 모든 AI 작업이 이것으로 돕니다 |
| Git | 프로젝트 폴더와 샌드박스 워크트리를 만듭니다 |

## 이 튜토리얼의 화면

튜토리얼의 화면과 결과는 모두 Robo Architect Lite 데스크톱 앱(macOS)을 실제로 실행해 얻었습니다. AI가 만드는 설계와 코드는 실행할 때마다 조금씩 다르므로, 여러분 화면의 글자가 그림과 똑같지 않아도 괜찮습니다. 각 장의 **확인할 것**에 적힌 요소가 있으면 됩니다.
