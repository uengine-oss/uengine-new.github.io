# 한빛 딜리버리 요구사항

한빛 딜리버리는 동네 음식점과 고객을 잇는 음식 배달 서비스다.

## 1. 주문
- 고객은 가게의 메뉴를 골라 장바구니에 담고 주문할 수 있어야 한다
- 고객은 가게가 주문을 접수하기 전까지 주문을 취소할 수 있어야 한다
- 고객은 주문 상태(접수 대기, 조리 중, 배달 중, 배달 완료)를 조회할 수 있어야 한다

## 2. 가게와 메뉴
- 사장님은 메뉴를 등록하고 가격과 설명을 수정할 수 있어야 한다
- 사장님은 재료가 떨어진 메뉴를 품절로 표시할 수 있어야 한다
- 사장님은 들어온 주문을 접수하거나 거절할 수 있어야 한다
- 사장님이 주문을 접수하면 조리가 시작된다

## 3. 결제
- 시스템은 주문할 때 결제를 처리해야 한다
- 주문이 취소되거나 거절되면 결제가 자동으로 환불되어야 한다

## 4. 배달
- 조리가 끝나면 시스템은 가까운 라이더에게 배달을 배정해야 한다
- 라이더는 음식을 픽업하고 배달 완료를 기록할 수 있어야 한다

## 5. 알림
- 주문이 접수되면 고객에게 알림을 보내야 한다
- 배달이 시작되면 고객에게 예상 도착 시간을 알려야 한다
