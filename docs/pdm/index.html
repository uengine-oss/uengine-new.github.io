시작하기

공개 데이터(NASA IMS·SKAB·CWRU)를 활용해 진동 센서 하나로 설비 고장을 미리 알아채는 법을 배웁니다. 이어서 페인트 교반기의 16주 합성 데이터로 Agentic AutoML을 운영해 봅니다. 에이전트가 모델을 고르고 섀도 모드로 검증해 승격하는 과정입니다. 모든 그림과 수치는 실제로 실행한 결과입니다.

실습 코드

이 교재의 실습 코드(교재 스크립트 5개, 운영 하네스 pdm_agent/, 대시보드, 시험)는 공개 준비 중입니다. 그전까지는 각 장 본문에 실은 코드와 명령으로 따라 할 수 있습니다.

무엇을 배우나#

페인트 교반기를 쓰는 회사가 "언제 고장 날지 모르겠다, 데이터를 줄 테니 뭐라도 해 봐라"라는 문제를 내놓았다고 합시다. 이 교재는 그 문제를 푸는 순서를 그대로 따라갑니다.

장 하는 일 쓰는 데이터
1. 공개 데이터와 기존 모델 지도 캐글·NASA·SKAB·CWRU에서 쓸 만한 데이터와 모델을 고르고, 기존 모델의 점수를 같은 규약으로 다시 계산합니다 SKAB
2. 진동 센서 하나로 이상 찾기 진동 스냅숏을 특징으로 바꾸고, 물리 공식·한 페이지 오토인코더·제로샷의 알람이 고장 몇 시간 전에 울리는지 비교합니다 NASA IMS
3. 고장 패턴 검색과 제로샷 진동 창을 벡터로 바꿔 과거 고장과 비교하고, Chronos-2를 학습 없이 사용합니다 CWRU, NASA IMS
4. 교반기 PBL 문제와 합성 데이터 센서·레시피·고장·정비 기록이 있는 16주 합성 데이터를 만듭니다 교반기 M-201(가상)
5. 에이전트 운영: 섀도와 승격 데이터가 매주 들어올 때 에이전트가 후보를 학습하고, 섀도 성적과 규칙에 따라 승격을 정합니다. 성능이 정체되면 코딩 에이전트가 새 후보 코드를 작성합니다 교반기 M-201
6. PBL 과제와 평가 학생 팀 과제, 평가 기준, 회사 데이터로 바꿔 끼우는 법

KANG 판 실습

왜 이렇게 짰나: 현장 전문가의 조언#

교재를 설계하며 예지보전 현장을 오래 겪은 전문가에게 들은 내용을 그대로 반영했습니다.

  • 실제 공장의 예지보전은 대부분 전문가가 준 물리 계산식과 알람 구간으로 운영됩니다. 머신러닝이 잘 맞는 곳은 펌프·모터처럼 진동만 보면 되는 단일 부품입니다.
  • 고장 라벨이 적으므로, 결국 사람이 무엇이 이상인지 판단해 라벨을 붙입니다. 학생 과제에서는 다변량을 피하고 진동 센서 하나를 쓰는 것이 좋습니다. 정상만 배우는 간단한 모델과 합성 데이터로 시작합니다.
  • 시계열을 512~1,024차원 벡터로 바꿔 벡터 DB에 넣고 과거 고장 구간과 비교하는 방법, Amazon Chronos 같은 파운데이션 모델로 학습 없이 점수를 내는 방법도 있습니다(3장).
  • 앞으로는 모델을 사람이 직접 고치기보다, 코딩 에이전트에 데이터를 주기적으로 주고, 에이전트가 스스로 모델을 선택·재학습한 뒤 섀도 모드로 검증해 승격하는 운영으로 옮겨 갑니다(5장).

준비물#

  • macOS 또는 Linux, Python 3.12, uv
  • 디스크 약 2 GB(NASA IMS 원본 1.07 GB)
  • 5장의 코딩 에이전트까지 실습하려면 Claude Code가 필요합니다(claude 명령, 로그인 상태). 없으면 시험용 고정 후보로 같은 흐름을 볼 수 있습니다.
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python numpy pandas pyarrow scipy scikit-learn matplotlib lightgbm "flaml[automl]" torch "chronos-forecasting>=2.0" pytest

macOS 에서 torch 와 lightgbm 을 함께 쓸 때

한 프로세스에서 Chronos(torch)와 lightgbm(FLAML)을 같이 쓰면 프로세스가 비정상 종료됩니다(exit 139, torch 2.15에서 확인). 스크립트 맨 위에서 os.environ["OMP_NUM_THREADS"] = "1"을 설정하고 lightgbm을 torch보다 먼저 불러오세요.
