한 장 요약

이 튜토리얼에서 쓴 말과 버튼을 일의 종류별로 한곳에 모았습니다. 문장은 예시일 뿐이니 그대로 외울 필요는 없습니다. 무엇을, 어떤 모양으로 원하는지만 분명하면 비서가 알아듣습니다.

화면#

하고 싶은 것 누를 것
홈(할 일 카드) 펴기·접기 왼쪽 위 원형 집 버튼
채팅 · 프로젝트 · 폴더 오가기 위 가운데 세 칸
팀원 메시지, 받은 공유·멘션 오른쪽 위 「메시지」
지난 대화에서 찾기 오른쪽 위 「검색」
설정(예약·팀·스킬·계정·지갑·보안) 오른쪽 끝 이름 첫 글자 동그라미
테마 자동·낮·밤, 하늘 미리보기 설정 › 시스템 설정
메일 지금 읽기 설정 › 시스템 설정 › 메일 확인 「지금 확인」
주제별 대화 목록 채팅 맨 위 「대화 N개 · 맥락별로 보기」
한 대화의 파일 모아 보기 그 대화 안에서 오른쪽 아래 산출물 더미

키보드#

키 동작
Enter 보내기
Shift+Enter 줄 바꾸기
@ 팀원 고르기 (↑↓로 옮기고 Enter·Tab으로 넣기)
Esc 산출물 더미 접기, 검색·메신저 닫기, 팀원 고르기 닫기, 새 패널 만들기 취소
Backspace (빈 입력창) 마지막으로 넣은 팀원 칩 지우기

나와 AI 비서 (3~6장)#

하고 싶은 것 이렇게 말하거나 누르기 장
요청 정리 아래 요청을 표로 정리하고 준비할 것을 체크리스트로 만들어 줘 + 원문 붙여 넣기 3장
파일로 받기 이 내용을 워드 문서로 만들어 줘. 파일 이름은 "…docx" (한글 hwpx·엑셀 xlsx·파워포인트 pptx도 됨) 3장
파일 넘겨주기 📎 버튼, 끌어다 놓기, 붙여 넣기 (50MB까지) 3장
말로 입력 입력창의 🎙 3장
답 멈추기 답을 쓰는 동안 입력창 오른쪽 위의 「멈추기」. 기다리는 중에 더 보낸 말은 「대기」 뒤 이어서 답함 3장
다른 일 끼워 넣기 그냥 말합니다. 비서가 새 주제인지 앞 이야기의 후속인지 판단합니다 4장
한 대화에 이어 말하기 그 대화에 들어가서 말하거나, 답 위 “↳ …” 줄을 눌러 들어갑니다 4장
메일 연결 첫 화면의 「Google에 로그인」·「메일 연결하기」 → Google 계정 / IMAP / 데모 메일함. 나중에 바꾸려면 「설정 › 계정 › 연결」의 「연결 바꾸기」 5장
연습 메일 받기 (데모 메일함) 「설정 › 시스템 설정」 또는 「설정 › 계정」 › 「연습 메일 받기」에서 메일을 골라 받기 5장
메일이 만든 할 일 처리 홈의 Reply·Pay·Book… 카드를 누르기 (치우려면 ×) 5장
사이트에서 일 시키기 ○○ 사이트에 로그인해서 지난달 주문 내역을 알려 줘 6장
브라우저 작업 크게 보기·직접 하기 작업 카드의 확장 버튼 → 「직접 제어」 → 「제어 돌려주기」 6장
비밀번호·카드 맡기기 대화에 뜬 보관함 카드에 입력, 또는 설정 › 계정 「+ 로그인 추가」, 설정 › 지갑 6장
결제 전에 확인받기 할 일만 말하면 결제 직전에 승인 카드가 저절로 뜸 → 「승인」 (지시에 “승인을 받아”는 넣지 않기) 6장

문서와 도구 (7~9장)#

하고 싶은 것 이렇게 말하거나 누르기 장
문서 열고 고치기 파일 카드를 누르면 이음오피스 편집기가 열림 → 열어 둔 채 합계 행을 굵게 해 줘처럼 말하기 7장
문서의 한 부분을 가리켜 말하기 편집기에서 표·그림·셀 범위를 눌러 @표 2, @B3:D6처럼 입력창에 넣고 말하기 7장
도면·그림·소리·영상 캐드크래프트로 매장 평면도 그려 줘, 열린 앱을 띄운 채 벽 색을 바꿔 줘 8장
고객 메일에서 초안까지 문서를 요청하는 메일이 오면 비서가 묻지 않고 초안을 만들고 홈에 「Review」 카드 9장

반복 줄이기 (10~12장)#

하고 싶은 것 이렇게 말하거나 누르기 장
잘된 방법을 스킬로 저장 방금 한 방식을 "매장 설계 제안 초안" 스킬로 만들어 줘 10장
정해진 시각에 반복 매주 월요일 9시에 진행 중인 제안 현황을 요약해 줘 → 채팅에 “예약됨” 칩, 관리는 설정 › 예약된 작업 11장
외부 서비스 연결 설정 › 계정 › 연결 (Google·YouTube·Slack·GitHub·Notion) 11장
팀이 쓰는 미니앱 홈 「새 패널 만들기」 또는 제안 파이프라인 관리하는 패널 만들어 줘 12장
미니앱에 기록 제안 파이프라인에 달빛커피 2호점 추가해 줘 12장

팀으로 일하기 (13~16장)#

하고 싶은 것 이렇게 말하거나 누르기 장
함께 쓰는 폴더 위 「폴더」 → 새 폴더, 구성원과 권한 13장
파일 보내기 파일 카드·산출물 더미·편집기의 사람 모양 공유 버튼 14장
팀원에게 부탁 입력창에 @김민지 평면도 검토 부탁해요 14장
받은 일 이어서 하기 메시지 › 받은 편지함 › 「이어서 작업」 14장
1:1·그룹 대화 메시지 › 「+ 새 대화」 15장
원격 회의와 회의록 대화방에서 회의 시작 → 도우미가 자료를 띄우고, 끝나면 회의록이 방에 남음 16장

프로세스로 일하기 (17~19장)#

하고 싶은 것 이렇게 말하거나 누르기 장
프로세스 만들기 설계 제안 요청이 오면 도면·제안서·견적을 만들고 재무 검토 후 회신하는 프로세스를 만들어 줘 17장
프로세스 시작·확인 설계 제안 프로세스 시작해 줘, 진행 중인 프로세스 보여 줘, 내 할 일 보여 줘 18장
내 단계 처리 홈의 「결정」·「입력」 카드 (결재처럼 선택지가 있으면 카드에서 바로) 18장
역할 담당자 정하기 설정 › 팀·역할 (관리자만 바꿈) 18장
반복된 일을 프로세스로 관리자가 마이닝 추천을 열어 흐름·사례를 보고 「정식 등록」 19장

프로세스 개선 (20~22장)#

하고 싶은 것 이렇게 말하거나 누르기 장
어디서 시간이 새는지 홈의 「제약」 알림 › 「개선 보기」, 또는 「프로젝트」 › 프로세스 옆 「개선 분석 →」 › 「병목」 탭(열지도, 단계별 리드타임 분해, 인스턴스별 프로파일) 20장
낭비와 제약 찾기 개선 화면 「가치 흐름」 탭(흐름 효율), 「제약」 탭(수요·처리 능력·가동률, 5단계) 21장
개선하고 효과 확인 「크리티컬 패스」 탭(보통·늦을 때) → 「개선 실행」 탭에서 바꿀 단계를 「담기」(미리 계산) → 「개선안 적용」(새 버전) → 버전별 비교 22장

확장과 운영 (23~25장)#

하고 싶은 것 명령·위치 장
에이전트 작업실 프로세스 단계의 「동작 보기」 › 「작업실 열기」, 공유 폴더·변형 화면의 「작업실」, 파일 카드의 「작업실에서 열기」(대화 폴더 밖 파일은 「눌러서 열기」) 23장
설치·시작 ./install.sh (--profile full, --with-mining, --port 28080) 1장
업그레이드 ./install.sh --upgrade 1장
멈추기 · 모두 지우기 ./install.sh --uninstall · --uninstall --purge 1장
상태·로그 docker compose ps · docker compose logs -f server deepagents 1장
데모 로그인 끄기 .env의 DEMO_LOGIN=0 후 ./install.sh (개발 서버는 server/.env의 PRO_DEMO_LOGIN=0) 25장
팀원·역할 관리, 백업, 키 교체 설정 › 팀·역할(관리자), 권장 백업 절차, 보관함 키 명령 25장
보관함 검증·활동 설정 › 보안 「검증」 6장

잘 시키는 다섯 가지#

  1. 재료를 함께 — 원문, 파일, 숫자를 붙여 주면 지어내지 않습니다.
  2. 모양을 말하기 — 표로, 체크리스트로, 엑셀로, 파일 이름은 ….
  3. 첫 문장에 이름을 — “달빛커피 …”처럼 고객·행사 이름을 앞에 두면 대화가 잘 나뉘고 목록에서 찾기 쉽습니다.
  4. 나눠서 — 정리 → 확인 → 파일 → 공유. 중간에 바로잡기 쉽습니다.
  5. 위험한 일은 승인 받게 — 결제·발송·삭제 전에는 “나에게 먼저 물어봐”를 붙입니다.

설치·비용·보안처럼 따라 하다 생기는 질문은 다음 장에 모았습니다(28장).

확인 문제

  1. 장진영 팀장이 공유한 견적서를 박서연이 받아 자기 비서에게 검토를 맡기려면 어디를 누르나요?
  2. 정식 프로세스에서 내 차례가 된 단계는 어디에 어떤 모양으로 뜨나요?
  3. 비서에게 결제나 메일 발송처럼 되돌리기 어려운 일을 시킬 때, 지시에 무엇을 붙이면 좋을까요?
답
  1. 박서연 계정에서 오른쪽 위 「메시지」 › 「받은 편지함」의 그 공유에서 「이어서 작업」을 누릅니다(14장).
  2. 홈에 「결정」 또는 「입력」 카드로 뜹니다. 결재처럼 선택지가 있으면 카드에서 바로 고를 수 있습니다(18장).
  3. “결제 버튼을 누르기 전에 꼭 나에게 승인을 받아”처럼, 그 동작 전에 먼저 나에게 묻게 하는 말을 붙입니다(잘 시키는 다섯 가지의 5번).
