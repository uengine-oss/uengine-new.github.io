시작하기

「디자인 → MVP → 실제 구현」은 Claude Design으로 화면 시안을 만들고, Artifacts로 동작하는 MVP를 만든 뒤, Claude Code로 실제 앱을 만들고 확인하는 공개 교재입니다. 혼자 따라 할 수 있도록 실제 실행 화면과 요청, 확인 결과를 함께 담았습니다.

무엇을 · 왜#

AI에 앱을 만들어 달라고 요청하면 화면과 코드가 나옵니다. 그다음에는 무엇을 확인해야 하나요? 선택한 정보가 다음 화면에 전달되는지, 두 사람이 동시에 예약해도 한 사람만 성공하는지, 누가 무엇을 했는지 기록이 남는지 확인해야 합니다.

이 교재는 세 도구를 차례로 써서 그 질문에 답합니다. Claude Design에서 화면을 정하고, Artifacts에서 데이터를 연결해 동작을 확인하고, Claude Code에서 서버 규칙과 자동 테스트를 갖춘 앱으로 옮깁니다. 앞 단계에서 만든 파일을 다음 도구에 그대로 넘기는 것이 이 흐름의 핵심입니다.

모든 화면은 실제로 실행한 결과입니다. AI가 처음부터 모든 것을 맞혔다고 설명하지 않습니다. 프로토타입에서 고른 자리가 전달되지 않은 장면, 서버 포트가 겹친 상황, 실제 API 호출을 시험하지 못한 부분도 함께 다룹니다. 각 장의 요청대로 실행하고 자신의 결과와 비교해 보세요.

2026년 11월 4일에 올린 「AI 기획·설계 도구 실습」 교재는 이 교재로 바뀌었습니다.

단계마다 남는 것#

단계 도구 실습에서 남기는 것
디자인 Claude Design 와이어프레임, 고해상도 시안, 클릭 프로토타입, 시안 PNG
동작하는 MVP Artifacts 주차면 CSV를 읽어 추천하고 예약하는 MVP HTML
실제 구현 Claude Code React(Vite)·Express·SQLite 앱, 자동 테스트, 예약·취소 감사 기록

예제는 사내 지하 1층 주차장 예약 앱입니다. A·B 구역의 40면 가운데 날짜와 시간에 맞는 자리를 고르고 예약합니다. 예제 회사와 데이터는 가상이며, 10월 예약 데이터는 569건입니다.

누가 어디부터 보면 좋은가#

독자 시작할 곳 이 순서를 권하는 이유
기획자·PM 흐름과 도구부터 디자인·동작하는 MVP 직접 문구를 고치고 댓글로 요구를 전달하며, 시안과 실제 동작의 차이를 볼 수 있습니다
개발 리더·개발자 Claude Code로 실제 구현과 실제로 써 보기 계획·승인·구현·테스트 과정과 서버 규칙·동시성·감사 기록을 확인할 수 있습니다

개발 경험이 없어도 디자인과 MVP까지 따라 할 수 있습니다. Claude Code로 구현할 때부터는 터미널에서 폴더를 열고 명령을 실행합니다. 개발 리더가 실제 구현부터 시작할 때는 디자인 시안과 동작하는 MVP에 어떤 한계가 있는지도 함께 확인하세요.

장 목록#

시작 페이지만 글로 되어 있고, 나머지 장에는 실제 실행 영상이 있습니다.

장 하는 일 영상
시작하기 전체 구성과 시작 위치 선택 없음
흐름과 도구 세 도구, 시작 위치의 변화, 전달 파일 있음
디자인 와이어프레임, 직접 편집, 댓글, 재생, 내보내기 있음
동작하는 MVP PNG·CSV 첨부, 권한, 추천과 예약 있음
Claude Code로 실제 구현 계획·승인·구현·테스트·실행 있음
실제로 써 보기 동시 예약과 취소, 감사 기록 조회 있음
배포: Docker Compose와 쿠버네티스 컨테이너로 언제든 실행, kind 클러스터 배포, 클라우드로 옮길 때 있음

준비물#

구분 준비할 것
디자인·MVP claude.ai 계정, 실습 시안과 주차면.csv
실제 구현 Claude Code를 사용할 유료 플랜, Node.js, 주차면.csv와 2026-10_주차예약.csv, 감사 조회용 sqlite3

디자인은 무료 계정에서도 만들었지만 공유 기능이 없고 사용 한도를 빨리 채웠습니다. 녹화는 유료 Ultra 계정으로 진행했으며, 디자인·MVP는 Opus 5.5, Claude Code는 Sonnet 5.5와 버전 2.1.319를 사용했습니다. 기준일은 2026년 11월 7일입니다.

서버 구현에서는 Claude API 키 없이도 예약 실습을 할 수 있습니다. 키가 없으면 말로 예약하는 입력창을 숨깁니다.

메뉴·한도·모델 응답은 실습 시점에 따라 달라질 수 있습니다. 화면 문구가 조금 다르더라도 입력한 요구, 남긴 파일, 실제 확인 결과를 기준으로 비교하세요.
