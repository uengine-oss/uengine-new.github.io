시작하기

Windows PC에서 따라 하는 「법령 GraphRAG 실습」입니다. 위험물안전관리법(법률·시행령·시행규칙 PDF 3개)을 그래프로 만들고, Neo4j는 내려받아 직접 설치하며, 모든 명령은 Windows에 기본으로 들어 있는 PowerShell로 입력합니다. 준비(3장)부터 질의(9장)까지 다룹니다.

무엇을 만드나요#

국가법령정보센터의 위험물안전관리법 PDF를 조·항·호 단위의 Neo4j 그래프로 적재하고, Claude Code가 Neo4j MCP 서버로 그래프를 조회해 골든 퀘스천 다섯 개에 근거 조문과 함께 답하게 합니다.

항목 이 교재에서 쓰는 것
법령 위험물안전관리법 법률·시행령·시행규칙 = PDF 3개
Neo4j Neo4j Desktop 최신판을 내려받아 설치(자바 포함, JDK 설치 불필요)
셸 Windows PowerShell 5.1(기본 포함)과 PowerShell 7 모두에서 동작하는 명령

골든 퀘스천 다섯 개는 모두 위험물안전관리법 법률·시행령·시행규칙 안에서 답이 나옵니다. 법령이 하나라 파싱·적재·질의가 빨리 끝납니다.

그래프가 왜 필요한지(1장)와 GraphRAG가 질문에 답하는 과정(2장)은 운영체제와 상관없는 이론입니다. 실습 전에 아래 두 페이지를 먼저 읽어 두면 좋습니다.

  • 1. 왜 그래프인가
  • 2. GraphRAG 동작 과정

골든 퀘스천#

구축 의도는 「위험물 안전관리 매뉴얼 내부 구축」입니다. 스키마 설계(5장)의 출발점이자 9장에서 답을 채점하는 시험지입니다.

  1. 제조소등에서 위치·구조·설비 변경 없이 저장·취급하는 위험물의 품명·수량(지정수량 배수)을 바꾸려면 언제까지 누구에게 신고해야 하는가?
  2. 위험물안전관리자가 해임되거나 퇴직하면 관계인은 며칠 안에 다시 선임해야 하고, 선임한 뒤에는 어떤 절차를 밟아야 하는가?
  3. 정기점검을 마친 제조소등의 관계인은 점검 결과를 언제까지 누구에게 제출해야 하는가?
  4. 제조소등에서 위험물 유출 사고가 발생했을 때 관계인과 이를 발견한 사람은 각각 무엇을 해야 하며, 관계인이 응급조치를 하지 않으면 누가 명령할 수 있는가?
  5. 안전관리자 선임 의무(제15조)나 정기점검 의무(제18조)를 지키지 않으면 어느 벌칙·과태료 조항이 적용되는가?

필요한 기술 스택#

이 실습은 아래 구성 요소가 서로 맞물려 동작합니다. 그림으로 보면 PDF → (파이썬 코드) → Neo4j ← (MCP 서버) ← Claude Code입니다. 각 요소가 무엇이고 왜 필요한지, 어느 버전을 써야 하는지, 이미 설치되어 있는지 확인하는 방법과 공식 내려받기 주소를 정리했습니다. 실제 설치는 3장에서 순서대로 따라 합니다.

꼭 준비할 것#

준비물은 다섯 가지입니다.

준비물 한 줄 설명
1 Claude Code(Claude Pro 이상 유료 플랜으로 로그인) 스키마 설계·코드 작성·그래프 질의를 맡는 AI 에이전트
2 uv 파이썬과 패키지를 설치·실행하는 도구. Python 3.12도 uv가 알아서 내려받습니다
3 Git for Windows 단계마다 커밋. Claude Code가 명령을 실행할 때 쓰는 Git Bash 포함
4 위험물안전관리법 PDF 3개(법률·시행령·시행규칙) 그래프로 만들 법령 원문(국가법령정보센터)
5 Neo4j Desktop(최신판, APOC 플러그인 포함) 그래프 DB를 만들고 켜고 끄는 프로그램. Neo4j를 실행하는 자바가 들어 있습니다

Python은 따로 설치하지 않아도 되나요?

네, 따로 설치하지 않아도 됩니다. 6장에서 uv init --python 3.12로 프로젝트를 만들면 uv가 Python 3.12를 찾고, 없으면 자동으로 내려받아 그 프로젝트 전용으로 씁니다. 이미 다른 버전(예: Python 3.13)이 설치되어 있어도 서로 충돌하지 않습니다. 다만 파이썬 코드를 실행할 때는 python …이 아니라 uv run …을 써야 그 3.12와 설치한 패키지가 쓰입니다.

JDK(자바)는 따로 설치하지 않습니다

Neo4j는 자바로 만든 프로그램이지만, Neo4j Desktop 안에 Neo4j를 실행하는 자바가 들어 있습니다. 이 교재는 Cypher 질의도 모두 Neo4j Browser에서 실행하므로 PC에 JDK를 설치할 필요가 없습니다. 이미 다른 버전의 자바가 설치되어 있어도 Desktop에는 영향이 없습니다.

구성 요소별 설명과 내려받기#

PowerShell — 이 교재의 모든 명령을 입력하는 셸입니다. Windows 10/11에 기본으로 들어 있는 Windows PowerShell 5.1로 충분하고, 따로 설치한 PowerShell 7(pwsh)에서도 같은 명령이 동작합니다. 두 버전은 한글 파일 저장(BOM), 빈 문자열 인자, 파이프 인코딩이 다르게 동작해서, 이 교재는 양쪽에서 똑같이 동작하는 방법만 골라 썼습니다(예: 설정 파일은 -Encoding ascii로 저장, --tools "" 대신 --tools=).

  • 확인: 시작 메뉴에서 「Windows PowerShell」(파란 아이콘)을 열고 $PSVersionTable.PSVersion을 실행합니다. 5.1 또는 7.x이면 됩니다.
  • PowerShell 7을 원하면(선택): winget install --id Microsoft.PowerShell -e · learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows
  • 「PowerShell ISE」는 쓰지 마세요. 외부 프로그램의 한글 출력과 대화형 입력이 일반 창과 다르게 동작합니다.

Neo4j Desktop — 내 PC에서 Neo4j 데이터베이스(인스턴스)를 만들고, 켜고, 끄고, 플러그인을 설치하는 프로그램입니다. 인스턴스는 최신 Neo4j(Enterprise 판, 내 PC에서 개발·학습용으로 무료)로 만들어지고, 웹 화면 Neo4j Browser로 질의합니다. Neo4j를 실행하는 자바가 함께 들어 있습니다.

  • 내려받기: neo4j.com/deployment-center → Neo4j Desktop → 최신 버전 → Windows (x86 exe). 간단한 양식을 채우면 neo4j-desktop-<버전>-x64.exe(약 620MB)를 받습니다
  • 설치와 인스턴스 만들기는 3장에서 따라 합니다
  • 확인: Desktop을 열었을 때 인스턴스 목록이 보이면 설치된 것입니다

APOC — Neo4j용 확장 프로시저 모음입니다. 8장의 MCP 서버가 apoc.meta.schema로 그래프 스키마를 읽으므로 8장에서 설치합니다. Desktop의 플러그인 화면에서 인스턴스와 같은 버전을 설치하므로 따로 내려받지 않습니다.

  • 문서: neo4j.com/docs/apoc/current/installation
  • 확인: Neo4j를 띄운 뒤 RETURN apoc.version();

uv와 Python 3.12 — uv는 파이썬 자체와 가상환경, 패키지를 한 번에 관리하는 도구입니다. 파이썬을 따로 설치하지 않아도 uv가 프로젝트에 맞는 Python 3.12를 내려받습니다. 6장에서 PDF 파싱(PyMuPDF)과 Neo4j 적재(neo4j 드라이버) 코드를 uv run으로 실행하고, 8장의 MCP 서버도 uvx로 실행합니다.

  • 설치: winget install --id astral-sh.uv -e 또는 powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  • 내려받기: docs.astral.sh/uv/getting-started/installation
  • 6장에서 쓰는 패키지: PyMuPDF · neo4j 드라이버 · python-dotenv
  • 확인: uv --version, uv python list

Git for Windows — 단계마다 결과를 커밋해 되돌릴 수 있게 합니다. Windows용 Claude Code는 명령을 실행할 때 이 안에 들어 있는 Git Bash를 쓰므로 Claude Code보다 먼저 설치합니다.

  • 설치: winget install --id Git.Git -e
  • 내려받기: git-scm.com/downloads/win
  • 확인: git --version

Claude Code — 터미널에서 동작하는 Claude의 코딩 에이전트입니다. 5~7장에서 스키마 설계와 적재 코드 작성을, 9장에서 MCP로 그래프 질의를 맡습니다. Claude Pro 이상 유료 플랜 계정으로 로그인합니다.

  • 설치: irm https://claude.ai/install.ps1 | iex
  • 문서: docs.claude.com/en/docs/claude-code/setup
  • 확인: claude --version

Neo4j MCP 서버 — MCP(Model Context Protocol)로 Claude Code에 Neo4j 조회 도구(get-schema, read-cypher)를 제공하는 공식 서버입니다. PyPI의 neo4j-mcp-server 2.1.2에 Windows용 휠(win_amd64·win_arm64)이 있어 uvx가 처음 실행할 때 알아서 내려받습니다.

  • 저장소·문서: github.com/neo4j/mcp · neo4j.com/docs/mcp/current · pypi.org/project/neo4j-mcp-server
  • 확인: uvx neo4j-mcp-server@2.1.2 --version

한 번에 확인하기#

이미 설치한 것이 있는지 PowerShell 창에 아래를 붙여 넣어 한 번에 봅니다. 없는 프로그램은 없음으로 나옵니다.

foreach ($c in 'powershell','pwsh','git','uv','claude') {
  $p = Get-Command $c -ErrorAction SilentlyContinue
  '{0,-11} {1}' -f $c, ($(if ($p) { $p.Source } else { '없음' }))
}

Neo4j Desktop은 명령이 아니라 프로그램이므로 시작 메뉴에서 「Neo4j Desktop」이 보이는지로 확인합니다.

실행 기록에 대해#

확인 문제#

위험물안전관리법 하나(PDF 3개)만 적재해도 골든 퀘스천 다섯 개에 모두 답할 수 있는 이유는 무엇인가요?

다섯 질문의 근거 조문(법 제6조·제15조·제18조·제27조와 벌칙 제35~39조, 이를 받는 시행령·시행규칙 조문)이 모두 위험물안전관리법 3종 안에 있기 때문입니다. 9장의 기록에서도 다섯 답의 근거 조문은 모두 위험물안전관리법·시행령·시행규칙이었습니다.

이 교재에서 도구를 모두 끌 때 `--tools ""`가 아니라 `--tools=`로 쓰는 까닭은 무엇인가요?

Windows PowerShell 5.1은 외부 프로그램에 빈 문자열 인자("")를 넘기지 못하고 빼 버립니다. 그러면 --tools 뒤의 다음 인자가 값으로 잘못 들어갑니다. --tools=는 5.1과 7 모두에서 「빈 값」으로 정확히 전달됩니다.
