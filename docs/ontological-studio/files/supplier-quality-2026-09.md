# 협력사 품질 현황 — 2026년 9월

구매팀이 매달 정리하는 협력사 품질 보고서다. 이번 달에는 협력사 세 곳, 부품 세 가지, 완제품 한 가지를 다룬다.

## 협력사

- **골드라인 PCB** — 중국 선전에 있는 1차 협력사. PCB 기판을 공급한다. 담당자는 구매팀 김민수 대리.
- **닝보 마그네틱스** — 중국 닝보에 있는 1차 협력사. 마그넷 코어를 공급한다. 담당자는 구매팀 김민수 대리.
- **대성케이블** — 경기도 안산에 있는 2차 협력사. 전원 케이블을 공급한다. 담당자는 구매팀 이지은 주임.

## 부품과 완제품

- 완제품 **스마트 컨트롤러 SC-100** 은 PCB 기판, 마그넷 코어, 전원 케이블 세 부품으로 조립한다.
- PCB 기판의 안전재고는 500장, 마그넷 코어는 300개, 전원 케이블은 1,000개다.

## 이번 달 품질 이슈

- **QI-0903** (9월 3일, 심각도 높음) — 골드라인 PCB 가 납품한 PCB 기판에서 납땜 불량이 발견됐다.
  해당 로트는 전량 격리했고, 김민수 대리가 시정 조치를 요청했다.
- **QI-0830** (8월 30일, 심각도 낮음) — 대성케이블이 납품한 전원 케이블의 포장이 파손된 채 입고됐다.
  제품 자체에는 이상이 없어 이지은 주임이 재포장 후 사용하기로 했다.

## 납기

- 골드라인 PCB 의 9월 선적분은 세관 보류로 아흐레 늦어졌다.
- 닝보 마그네틱스와 대성케이블은 납기를 지켰다.
