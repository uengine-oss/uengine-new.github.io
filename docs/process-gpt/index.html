Process GPT 튜토리얼

회사의 반복 업무를 말로 설명해 프로세스로 만들고, AI 에이전트 동료에게 회사 문서를 가르치고, 외부 도구와 업무 규칙을 붙여 가며 Process GPT를 처음부터 한 단계씩 익히는 실습서입니다.

Process GPT는#

Process GPT는 업무 프로세스와 AI 에이전트를 함께 다루는 오픈소스 플랫폼입니다. 업무의 순서와 담당은 국제 표준 표기인 BPMN으로 정하고, 각 단계는 사람이 하거나 AI 에이전트가 맡습니다. BPMN을 그릴 줄 몰라도 됩니다. 만들고 싶은 업무를 채팅으로 설명하면 Process GPT가 흐름도와 입력 폼을 만듭니다.

이 튜토리얼은 사무용 가구 회사 한빛오피스의 이야기를 따라갑니다.

등장인물 역할
장진영 영업팀장. 이 튜토리얼에서 여러분이 맡는 사람이자 Process GPT 관리자입니다
김민지 영업 담당. 고객 요청을 받고 제안서를 씁니다
박서연 재무 담당. 큰 금액의 견적을 승인합니다
한빛오피스 견적 상담가 가격표를 보고 견적 초안을 쓰는 AI 동료(9장에서 만듭니다)
  1. 시작하기 — Process GPT를 설치하고 화면을 둘러봅니다.
  2. 프로세스 기본 — 「영업 제안서 작성」 업무를 채팅으로 설명해 프로세스로 만들고, 만들어진 정의(흐름도·역할·폼)를 들여다보고 버전을 관리합니다.
  3. AI 에이전트 — 제품 가격표를 지식 베이스에 올려 근거로 답하게 하고, 견적 초안을 쓰는 에이전트 동료를 만들어 대화합니다. 견적 승인 규정으로 에이전트가 들어간 프로세스를 만듭니다.
  4. 도구와 규칙 — 수량 할인 기준을 대화로 결정표(DMN)로 만들어 에이전트에게 붙입니다.
  5. 운영 — 동료를 들이고 화면 언어와 설정을 바꿉니다.

학습 순서#

시작하기설치와 첫 로그인, 화면 둘러보기 프로세스 기본대화로 프로세스 만들기, 정의 들여다보기와 버전 AI 에이전트지식 베이스, 에이전트 동료 만들기·대화, 문서로 프로세스 만들기 도구와 규칙대화로 만드는 결정표(DMN) 운영동료 가입, 언어, 설정

각 장은 왜 → 따라 하기 → 확인 문제 순서로 되어 있습니다. 앞 장에서 만든 것을 다음 장에서 이어 쓰므로 순서대로 따라 하는 것이 좋습니다. 확인 문제의 답은 접혀 있으니, 먼저 스스로 해 본 뒤 펼쳐 보세요.

준비 중인 장

왼쪽 목차에서 「준비 중」으로 표시된 장(조직도와 역할 담당자, 실행하고 할 일 처리하기, 승인과 반려, 스킬, 에이전트가 맡는 단계 실행, MCP로 외부 도구 연결하기, 실행 분석, 전략 보드, 종합 과제)은 현재 버전에서 고치고 있는 부분을 반영한 뒤 차례로 공개합니다. 장 번호는 미리 정해 두었으므로 나중에 공개되어도 바뀌지 않습니다.

누구를 위한 튜토리얼인가#

  • 메일과 메신저로 일해 본 사람이면 따라 할 수 있습니다. 프로그래밍은 필요 없습니다.
  • 설치(1장)는 터미널에 명령 몇 줄을 붙여 넣을 수 있으면 됩니다.
  • BPMN을 몰라도 됩니다. 필요한 만큼은 장 안에서 설명합니다.

이 튜토리얼의 화면#

튜토리얼의 화면과 결과는 모두 1장의 방법으로 Process GPT를 새로 설치해 실제로 실행해 얻었습니다. AI가 만드는 문장과 흐름은 실행할 때마다 조금씩 다르므로, 여러분 화면의 글자가 그림과 똑같지 않아도 괜찮습니다. 각 장의 확인할 것에 적힌 요소가 있으면 됩니다.
