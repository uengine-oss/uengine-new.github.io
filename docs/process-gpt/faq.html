자주 묻는 질문

튜토리얼을 만들며 실제로 부딪힌 문제와 푸는 법입니다. 장 번호를 따라가면 자세한 설명이 있습니다.

설치와 로그인#

http://localhost:8088 이 열리지 않아요.
런처가 끝까지 돌았는지 봅니다. 처음에는 이미지를 받느라 오래 걸립니다. docker compose ps로 nginx가 떠 있는지 확인하고, 없으면 ./start-all-services.sh …를 한 번 더 실행합니다. 다른 프로그램이 8088 포트를 쓰고 있으면 그 프로그램을 끕니다(1장).
가입하려는데 이메일 형식이 틀렸다고 나와요.
@ 뒤에 점이 있어야 합니다. jinyoung@hanbit.example처럼 씁니다. 로컬 설치본은 메일을 보내지 않으므로 실제 주소가 아니어도 됩니다(1장).
두 번째로 가입한 동료가 관리자가 아니에요.
정상입니다. 처음 가입한 사람만 관리자이고, 그 뒤에 가입한 사람은 일반 사용자로 들어옵니다(18장).
채팅을 보냈는데 「샌드박스를 사용할 수 없습니다」라고 해요.
딥 에이전트가 작업 컨테이너를 띄우지 못한 것입니다. 1장의 docker-compose.override.yml을 만들고 다시 띄웁니다.
처음부터 다시 하고 싶어요.
./stop-all-services.sh --wipe 뒤에 런처를 다시 실행합니다. 모든 데이터(가입한 계정, 프로세스, 문서)가 지워집니다.

채팅과 프로세스#

같은 문장을 보냈는데 그림과 답이 달라요.
AI가 만드는 글과 흐름은 실행할 때마다 조금씩 다릅니다. 장마다 「확인할 것」(단계 이름, 금액, 규칙 등)이 맞으면 됩니다.
버전 비교 화면의 프로세스 계층에 「unknown」이 보여요.
현재 버전의 표시 문제입니다. 「미분류 › unknown › 미분류」를 끝까지 펼쳐 프로세스를 고릅니다(4장).
단계 이름을 바꿨는데 다시 열면 그대로예요.
단계 패널의 💾는 흐름도에만 반영합니다. 정의 화면 오른쪽 위 💾로 정의를 저장해야 버전이 생깁니다(4장).
딥 에이전트가 「결과 전달을 보류했어요」라며 프로세스를 내주지 않아요.
딥 에이전트가 만든 정의가 검사를 통과하지 못한 것입니다. 같은 대화방에서 다시 만들어 달라고 하거나, 새 대화에서 요청을 더 구체적으로(단계와 담당, 갈림길) 적어 보냅니다(12장).

지식 베이스와 에이전트#

.md 파일을 올렸더니 「지원하지 않는 형식」이래요.
지식 베이스는 PDF, HWP, HWPX, DOC, DOCX, PPTX, TXT, CSV, XLSX를 받습니다. PDF나 TXT로 바꿔 올립니다(8장).
지식 베이스에서 폴더를 골랐더니 문서를 못 찾는대요.
현재 버전에서는 폴더 선택이 에이전트에게 전달되지 않습니다. 폴더를 펼쳐 파일에 체크합니다(8장).
문서를 골랐는데 에이전트가 자료를 달라고 되물어요.
질문 앞에 “선택한 지식 베이스의 ○○ 문서를 찾아보고”를 붙입니다(8장).
에이전트 화면에서 「파일 첨부」로 붙인 파일을 에이전트가 못 읽어요.
현재 버전에서는 그 첨부가 에이전트에게 가지 않습니다. 문서를 지식 베이스에 올리고, 대화목록에서 그 대화방을 다시 열어 ＋ › 「지식 베이스」로 고릅니다(10장).
에이전트의 「도구 목록」에 있는 「가격계산기」는 무엇인가요?
에이전트를 만들 때 AI가 지어 넣은 이름입니다. 도구 칸은 MCP 서버 이름이라, 그런 이름의 MCP 서버가 없으면 아무 도구도 붙지 않습니다(9장).
에이전트 설정 창의 「성과 & 뱃지」 숫자가 이상해요.
현재 버전에서는 모든 에이전트에 같은 예시 값이 나옵니다. 실제 기록이 아닙니다(9장).
결정표 저장 단추가 눌리지 않아요.
DMN 저장 창의 「이름」을 적어야 합니다(15장).

설정#

화면이 영어로 바뀌었어요.
⚙ 설정의 탭 줄 끝 「English」를 눌러 「한국어」를 고릅니다(18장).
「용어집 관리」 탭에 오류가 나요.
현재 설치본에는 그 기능의 표가 없어 「relation public.glossaries does not exist」가 나옵니다. 튜토리얼에서는 쓰지 않습니다.
