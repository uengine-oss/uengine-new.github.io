창과 탭#

하고 싶은 것 방법
홈으로 ⌘1 (탭 줄의 홈)
N번째 탭으로 ⌘2 부터 순서대로
다음 탭 Ctrl+Tab
두 화면을 나란히 탭 우클릭 → 새 창으로 분리
한 탭 안에서 화면 바꾸기 왼쪽 레일 (레거시 탭의 레일은 레거시 메뉴만)
밝게 · 어둡게 탭 줄 오른쪽 해 · 달 단추 — 홈과 모든 탭이 함께 바뀐다
다른 프로젝트로 홈 위쪽 프로젝트 줄 → 프로젝트 바꾸기

프로포절 단계#

상태 뜻 누르는 것 걸린 시간(이 튜토리얼)
INTENT 전략 설계(바운디드 컨텍스트 · 기능 · 스토리 · 인수 조건) + 새 Proposal → AI 분석 시작 약 2분
PLAN 헌장(처음 한 번) → 전술 설계 · 아키텍처 결정 Plan 단계로 진행 → → Plan 생성 → Plan 확정 약 10분
SUBMITTED 계획이 확정됨 샌드박스 구현 칸 → 작업 목록 생성 약 1.5분
IMPLEMENTING 샌드박스(Git 워크트리)에서 Claude Code가 구현 구현하기 → Claude Code 셀로 이동
VALIDATING · 승인 대기 구조 동기화 + 인수 조건 검증 구현 완료 → 검증
ACCEPTED · DESTROYED Accept (Dual Merge) 는 코드와 그래프 DB를 함께 반영하고, Destroy 는 버린다(Diff 이력은 보관) Accept / Destroy 칸

생성 중에는 그 탭에 머물기

Plan 생성처럼 오래 걸리는 단계는 그 탭을 새로고침하거나 그 탭에서 화면을 옮기면 처음부터 다시 시작합니다. 다른 일은 홈에서 새 탭을 열어 합니다.
