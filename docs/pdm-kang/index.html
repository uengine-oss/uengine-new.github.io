시작하기

공장에서 사용하는 형태의 설비 고장 예측 프로그램(KANG 설비 고장 예측 시스템 v0.5.1)을 직접 실행하며 예지보전을 배웁니다. 실시간 가상 RTU를 함께 실행해 이상 신호를 발생시킵니다. 모델이 학습하고 알람을 내는 과정을 확인합니다. 이어서 고장 분류를 정하고 고장 기록을 넣었을 때 같은 프로그램이 어떻게 달라지는지, 페인트 교반기의 실제 고장 유형을 재생해 무엇이 보이는지 실험합니다.

무엇을 배우나#

페인트 공장의 교반 설비에서 고장을 미리 알아채는 프로그램을 공장에 도입한다고 가정합니다. 이 교재는 프로그램 설치, 데이터 연결, 결과 해석 순서로 진행합니다. 이어서 현장 데이터를 넣을 준비를 합니다.

장 하는 일 영상
1. 배경: 예지보전과 페인트 교반기의 고장 보전 방식, 페인트 공장 설비, 고장 유형, 센서별로 보이는 고장, 공개 사례 있음
2. 설치와 실시간 연결 가상 RTU와 예측 시스템을 띄우고 연결합니다. 연결 즉시 모델이 학습됩니다 있음
3. 이상 신호를 내며 학습시키기 수동 이상을 발생시켜 규칙 알람, AI 알람, 팝업, 이상 PDF, 재학습을 확인합니다 있음
4. 고장 분류를 정하고 고장 기록 넣기 failure_label이 붙은 10일 파일로 「60분 안에 걸림」 확률 모델을 학습합니다 있음
5. 교반기 고장 재생과 재학습 설정 시나리오 RTU로 펌프 막힘·베어링 열화·레시피 변경을 재생하고, 자동 학습을 켜고 끈 결과를 비교합니다 있음
6. 과제와 현장으로 가는 길 팀 과제, 평가 기준, 현장 데이터 수집 체크리스트

KANG 개발 측의 안내#

이 교재는 KANG 시스템 개발 측의 안내를 그대로 따릅니다.

  • 실제 프로그램을 돌려 보세요. 실시간 RTU 시뮬레이터를 함께 실행해 이상 신호를 발생시키고 모델을 학습시키는 데서 시작합니다(2·3장).
  • 고장 정보는 현장에서 정해야 합니다. 지금의 예측 시스템은 고장 정보를 넣지 않고 정상 패턴만 배웁니다. 고장 내역·종류·기록으로 분석하려면 실제 고장 정보로 진행하거나, 고장 종류를 분류해서 진행해야 합니다. 이 분류는 현장에서 수집한 데이터로 정의해야 합니다. 고장 분류를 정의하고 데이터를 넣으면 같은 방법으로 진행할 수 있습니다(4장).
  • 에이전트는 붙어 있지 않습니다. 이 시스템은 머신러닝 분석과 보고까지 수행합니다. 에이전트가 모델을 고르고 바꾸게 하려면 에이전트용 API를 따로 연결해야 합니다. 이 기능은 기본 배포본에 포함되지 않습니다.

「설비 예지보전 PBL」 교재와 무엇이 다른가#

같은 문제(페인트 교반기)를 다른 관점에서 살펴봅니다. 두 교재를 함께 보면 현장 시스템에 무엇이 필요한지 알 수 있습니다.

설비 예지보전 PBL 이 교재(KANG 판)
센서 모터 베어링 하우징의 가속도계 하나, 5,120 Hz 전류·진동 RMS·온도·압력 네 채널, 1분 간격(PLC·RTU에서 받는 형태)
잘 보는 고장 베어링 외륜 손상, 임펠러 부착 불균형 펌프 걸림, 압력 저하, 과부하 같은 공정 쪽 고장
모델 물리 공식, 오토인코더, 패턴 검색, 제로샷 20시점 창 특징 + Isolation Forest, 고장 기록이 있으면 Logistic Regression
운영 에이전트가 후보를 고르고 섀도 모드로 검증해 승격 정해진 시점마다 자동 재학습, 사람이 확인
고장 기록 정비 기록(시각·종류)으로 채점 failure_label(0/1)로 학습

준비물#

  • macOS, Windows 또는 Linux, Python 3.12(다른 버전은 지원하지 않습니다)
  • KANG 설비 고장 예측 시스템 배포본(KANG_PdM_RTU_배포본_20261109.zip, 1.2 MB) — 수업에서 받습니다
  • 4·5장 실습 파일(시나리오 RTU, 고장 기록 파일 생성기) — 각 장 본문에 코드를 실었습니다. 저장소는 공개 준비 중입니다
  • 처음 설치할 때 인터넷 연결(무료 Python 패키지를 받습니다)

합성 데이터입니다

배포본의 가상 RTU 데이터와 이 교재의 시나리오 데이터는 모두 합성 데이터입니다. 기능과 원리를 배우는 용도이며, 현장의 고장 예측 성능이나 안전 판단의 근거가 아닙니다. 예측 시스템은 설비를 제어하지 않습니다. 데이터를 받아 분석하고 표시하기만 합니다.
